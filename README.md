# 正鑫越设计学习笔记备份

这是正鑫越文化传播个人工作室的设计学习知识库备份，每天晚上自动同步更新。

## 内容

- `design-study/notes/`：设计学习笔记 —— 排版、美学、字体、品牌系统、包装、3D、动效，以及生产工艺标准卡（喷绘 / 印刷 / UV / 发光字 / 灯箱 / 3D 产品 / 餐饮范围与改稿政策）和印刷材质规格。
- `design-study/SYNTHESIS.md`：学习综合。
- `study/notes/`：每日自学（虎课品牌视觉等课程）笔记，按日期归档。

## 说明

- 本库是学习与参考资产，不是生产文件：涉及生产参数、材质与价格时，以供应商实测与客户确认为准。
- 已脱敏：不含电话、邮箱、账号、学号等个人信息；不含客户项目诊断与商业调研内容。
- 供 AI 与设计师直接学习参考，欢迎引用时注明来源。
