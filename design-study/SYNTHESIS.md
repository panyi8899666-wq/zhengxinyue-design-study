> 详细笔记：notes/aesthetics.md / notes/typography.md / notes/layout.md

## 一、排版铁律（Typography）

1. **横版断行第一原则**：宽度是资源。条目式内容（安全牌、制度）**一句一行**——阅读单位必须等于视觉单位，不让读者的大脑做"两行并一条"的合并运算。段落式内容（海报正文）才用"排满成块"。
2. **先看内容是条目还是段落，再选断行策略**——两者用反是灾难。
3. **不断词、不断标点、不留孤字**；标点全角，句号逗号禁行首。
4. **中西混排**：中文与数字/英文之间加空格（"铲斗离地 20～30cm"），数字与单位不加（"20cm"）。
5. **字号层级**：标题 ≥ 2× 正文；一页字号种类 ≤ 4 种。
6. **视认死锁**：字号、字数、版面宽度三者死锁——定稿前必须验算"字数×字高 ≤ 版面宽"，否则在 10m 距离下字太小等于白做。（DB35/T：4~5m→20mm 字高；10m→40mm）

## 二、布局铁律（Layout）

1. **网格先行**：边距取版宽 5%~8%，栏数取 4 的倍数；纯文字版至少守住"一条左对齐线 + 一条右边界线"。
2. **对齐铁律**：标题居中、正文左对齐；同一版面不混用多种对齐。
3. **亲密性**：条目间距 > 条目内行距（组距 ≥ 1.5× 行距），让"哪几行是一条"不言自明。
4. **行距**：标识牌取字号 1.3~1.5 倍；标题与正文间隔取组距 2 倍。
5. **视觉流检查**：眯眼看缩略图，第一眼必须落在标题上。

## 三、审美铁律（Aesthetics）

1. **颜色 ≤ 3 种**；明度对比是最强的对比——转黑白自检，糊成一团就是不及格。
2. **对比色并置必须加隔离**（白/黑描边、留白），否则边缘"打架"。
3. **安全色是国标不是审美**：蓝=指令（必须照做）、红=禁止/警示、黄=警告、绿=通行。先定内容类别再定底色。
4. **高级 = 克制 + 对比狠 + 留白 + 统一 + 细节**；土 = 什么都想要、什么都差一点。
5. **CRAP**：对比管主次、重复管统一、对齐管秩序、亲密管关系。
6. **系列物料先定样式板**（色值/字号/间距写死），再套用到每一张。

## 四、印刷交付铁律

1. 出血 3mm、安全边距 5~10mm（大牌按比例）。
2. 色彩模式 CMYK（或明确告知印刷厂 RGB 转印风险，亮蓝会变暗）。
3. 文字转曲，另存可编辑版。
4. PDF 导出后 PyMuPDF 溢出断言（已有流程，坚持执行）。
5. 大尺寸先确认工艺：写真/喷绘/印刷，材质影响色彩表现。

## 五、今日实战复盘（安全标识牌 70×50cm）

用新学的尺子量今天的活：

| 检查项 | 结果 |
|---|---|
| 一句一行（v3 版） | ✅ 7 条中 6 条一句一行，第 2 条过长换行（无奈但合理） |
| 数字空格 | ❌ "铲斗离地20～30cm"少了空格，应为"铲斗离地 20～30cm" |
| 视认距离 | ⚠️ 23px（~8mm）只够 2~4m 近看；10m 需 40mm 字高，但 28 字×40mm=1120mm > 700mm 版宽——死锁，下次接单先问观看距离 |
| 行距 | ⚠️ 48px/23px ≈ 2.08 倍，偏松；标识牌压到 1.5 倍更紧凑有力 |
| 出血 | ❌ 没加 3mm 出血，印刷裁切偏 1mm 就露白边 |
| CRAP | ✅ 对比/重复/对齐/亲密基本做到 |
| 网格边距 | ✅ 左 46mm ≈ 6.5%，在 5~8% 区间内 |

**结论**：v3 版在"不断行"这个核心要求上是对的，但有 3 个可改进点（数字空格、行距收紧、加出血），1 个结构性认知（视认死锁——下次先问距离再定字号）。

## 六、动效铁律（Motion，第六轮 2026-10-17）

> 详细笔记：notes/motion-design.md；实战诊断：practice/motion-diagnosis-site-tilt.md

1. **时长 200–500ms**：<100ms 等于没有，>1s 等于卡；交互反馈（悬停/点击）必须 ≤500ms；进入慢、离开快。
2. **缓动即语气**：位移永不用 linear；进入 ease-out（`(0.16,1,0.3,1)` 更柔），离开 ease-in；弹簧只给高光时刻。
3. **3D 倾斜卡片标准参数**：perspective ≈ 卡片宽 3–4 倍；幅度 **4–8°**（±2° 以下感知不到）；鼠标跟随必须 **rAF 插值平滑**（lerp 0.12–0.2），直接写鼠标坐标会抖；mouseleave 回正；仅 `pointer:fine` 桌面生效；尊重 `prefers-reduced-motion`；只动 transform/opacity。
4. **自动旋转能删就删**（WCAG 2.2.2）：改成用户驱动（悬停/点击/滚动触发）。
5. **动效分级**：一级（hero 入场）可华丽、二级（卡片悬停）克制、三级（按钮按压）极简；一次只动一个属性族。
6. **验收铁律**：录屏 0.5 倍速自查三问（时长≤500ms？离开回正了？手机上关掉了？）；**报的参数必须与代码一致**；桌面动效不要请用户在手机上验收——手机上根本跑不起来。
