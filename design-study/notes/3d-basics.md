## 一、3D 核心概念：建模 / 灯光 / 材质 / 渲染

### 1.1 建模（Modeling）：从无到有造形体

**概念**：三种主流方式。
- **多边形建模**：用顶点/边/面搭形体，像搭乐高。适合硬表面（机械、建筑、包装盒）。Blender 里 `Shift+A` 加立方体，`Tab` 进编辑模式，`E` 挤出——这就是全部。
- **曲面/细分建模**：多边形 + Subdivision Surface 修改器，棱角变圆滑。适合产品、角色身体。
- **雕刻**：像捏泥一样刷细节。适合有机形体（人物、动物、吉祥物）。

**为什么重要**：建模决定"形准不准"。潘熠吐槽案例"穿模"的根源之一，就是形体结构违反物理常识（不可能的结构、错的比例）——先有对的形，才谈得上渲染。

**工作落点**：吉祥物 v1 是程序化建模（build_mascot.py），"干净但缺灵魂"。下一步用 Tripo 从手绘稿转 3D，再进 Blender 修形——比从零捏快 10 倍。

### 1.2 灯光（Lighting）：三分模型七分灯

**概念**：再好的模型，灯光烂了直接降档。经典**三点布光**：
- **主光（Key）**：前方 45° 高位，强度最强，定基调、定明暗结构。
- **补光（Fill）**：对侧低位，强度为主光 1/3~1/2，柔化阴影、保住暗部细节。
- **轮廓光（Rim/Back）**：后上方，勾勒边缘，把主体从背景上"撕"下来，立体感就靠它。

强度比建议 3:1:1。**HDRI 环境光**是作弊器：一张 360° 高动态照片同时提供环境照明 + 真实反射，金属表面立刻有"窗户倒影"，档次瞬间上去（Poly Haven 有免费 4K HDR）。

**为什么重要**：人眼判断"真假"的第一信号是光影逻辑对不对。主光方向混乱、阴影死黑、没有环境反射——这三样是"假 3D"的重灾区。

**工作落点**："暗粒"包装盒要重做 3D 渲染感，灯光至少要：HDRI 打底 + 主光 45° + 轮廓光。缺了轮廓光，盒子就"粘"在背景上。

### 1.3 材质（Material）：PBR 四件套

**概念**：PBR（基于物理的渲染）用 4 个参数描述一切材质：
- **Albedo（反照率/基础色）**：物体固有颜色，不含光影。注意：纯黑（0,0,0）在 PBR 里几乎不存在——现实中没有绝对黑。
- **Metallic（金属度）**：0=非金属（木头/塑料/布），1=金属。非黑即白，中间值少用。
- **Roughness（粗糙度）**：0=镜面（高光锐利），1=完全漫反射（高光拍散）。这是"质感"差异的最大来源。
- **Normal（法线）**：用贴图伪造表面凹凸，不增加模型面数。砖缝、布纹、拉丝都靠它。

速查（Substance 风格）：
| 材质 | 粗糙度 | 金属度 |
|---|---|---|
| 抛光金属 | 0.1~0.2 | 1.0 |
| 磨砂塑料 | 0.6~0.8 | 0.0 |
| 清漆木材 | 0.4~0.6 | 0.0 |
| 玻璃 | 0.0~0.1 | 0.0（开折射，IOR≈1.5） |

**为什么重要**：材质错了，灯光再好也救不回来。最常见的错：塑料调得像金属（金属度误开）、所有东西粗糙度都是 0.5（"一视同仁"是最假的）。

**工作落点**：吉祥物是 Q 版黏土风——粗糙度 0.6~0.8、金属度 0，这是"黏土感"的配方。网站上的深色黏土胶囊按钮也是同理。

### 1.4 渲染（Rendering）：把计算变成图片

**概念**：两大路线。
- **光线追踪（Cycles/Arnold/V-Ray）**：模拟光线真实反弹，GI（全局光照）让暗部有环境色、不死黑。质量高、速度慢，适合静帧。
- **实时渲染（Eevee/游戏引擎）**：快，适合预览和动画，真实感靠"作弊"（烘焙、假阴影）。

**为什么重要**：理解"渲染器在算什么"，才能知道效果的边界——比如 Cycles 的 GI 是暗部不死黑的原因，Eevee 默认没有。

**工作落点**：出效果图用 Cycles（静帧不差那几分钟）；做网站上的 3D 展示才考虑实时方案。

## 二、"渲染感"从哪里来：7 条可操作

为什么有的图一看就是"3D 渲染的成品"，有的像"贴上去的"？拆开：

1. **全局光照（GI）**：光线在物体间反弹，暗部带环境色、不死黑。没有 GI 的图，阴影是"一刀切"的黑——人眼毫秒级识破。
2. **软阴影**：真实世界的阴影边缘都是渐变的（半影）。面光源越大、阴影越软。硬阴影=假。
3. **反射**：金属、玻璃、光滑塑料表面必须有环境反射（HDRI 的价值）。没有反射的金属像"灰塑料"。
4. **接触阴影（AO/Contact Shadow）**：物体和地面接触的地方一定有深色缝隙。没有它，物体像"浮"在空中——"穿模感"的头号来源。
5. **景深（DOF）**：焦点清晰、前后渐虚。没有景深的图，所有东西一样锐——现实中不存在。
6. **材质不完美**：真实表面有划痕、指纹、灰尘、磨损。100% 干净的材质=CG 味。用粗糙度贴图加一点"脏"，真实感翻倍。
7. **体积感/大气**：远景轻微雾化、暗角。没有空气感的图，远近没有距离。

**一句话**：渲染感 = 光影逻辑全对 + 材质物理全对 + 一点不完美。缺任何一条，人眼都会报警。

## 三、Blender 实战入门：2 小时第一个产品小场景

> 目标：零基础，2 小时，做出一张"能看"的产品小场景（比如一个杯子）。

**第 0~20 分钟：认路**
- 界面四块：3D 视图（干活区）、大纲视图（场景清单）、属性面板（调参数）、时间轴。
- 记住 5 个键：`G`移动 `R`旋转 `S`缩放，`Tab`切换物体/编辑模式，`Z`切换视图着色。
- `Shift+A`：加东西（网格/灯光/相机）。`F12`：渲染。

**第 20~60 分钟：建模**
- `Shift+A` 加圆柱体 → 当杯身；`Tab` 进编辑模式 → `S` 缩放调比例。
- 加圆环（Torus）当杯把；`E` 挤出做细节。
- 选中物体 → 右键 → Shade Smooth（变光滑）；加 Subdivision 修改器（更圆润）。

**第 60~90 分钟：材质+灯光**
- 选中杯子 → 材质面板 → New → Principled BSDF：Base Color 选釉色，Roughness 0.3（陶瓷），Metallic 0。
- 灯光：删默认点光 → `Shift+A` 加面光（Area）当主光放左前 45°；再加一个小面光当补光放右侧；世界属性里加一张 HDRI（环境纹理 → 环境贴图）。
- 相机：`Ctrl+Alt+小键盘0` 把当前视角设为相机视角。

**第 90~120 分钟：渲染输出**
- 渲染引擎切 Cycles（真实感），采样 128（预览）/ 512（出图）。
- 输出 1920×1080 PNG → `F12` → 等 → 存图。
- 进阶：渲染属性里开降噪（Denoise），颗粒感消失。

**学习资源**：Blender Guru（油管，新手甜甜圈教程是公认的第一课）、CG Cookie、Grant Abbitt。Blender 官方文档是最好的字典。

## 四、AI 3D 工具：Tripo / Meshy / Rodin

### 4.1 原理一句话

Image-to-3D：AI 看一张 2D 图，"脑补"出没看到的背面和侧面，生成带贴图的 3D 网格。本质是"有根据的猜测"——正面准、背面靠 prior（先验）。

### 4.2 效果边界（诚实版）

- **擅长**：角色、吉祥物、产品单体、概念验证。Q 版吉祥物是最佳场景（形体简单、对称、AI 先验充足）。
- **不擅长**：精密机械（尺寸要准）、多部件装配、薄壁镂空、文字/logo（AI 会把字画糊）。
- **拓扑**：AI 生成的网格通常是"看起来对、拓扑乱"——三角面多、布线混乱。Tripo 的 Smart Mesh / Retopology 功能就是干这个的：重建成干净的四边面。
- **贴图**：AI Texturing 能生成 PBR 贴图，但细节处（比如吉祥物脸上的腮红）可能需要手绘修正。

### 4.3 云端 AI 转 3D 完整工作流

1. **图片准备**：正面、光线均匀、背景干净、无遮挡、无透视变形。Q 版吉祥物三视图（正/侧/背）效果最好，单张也行。
2. **生成**：Tripo Studio → Image to 3D → 选 Smart Mesh（干净拓扑）→ 等 20~60 秒。
3. **检查**：转一圈看背面——AI 脑补的部分重点看，有没有多出手、多出面、贴图拉伸。
4. **清理拓扑**：Tripo 自带 Retopology，或导进 Blender 用 Quad Remesher 思路手动修。目标：四边面为主、布线顺形体走。
5. **贴图修正**：AI Texturing 出底版，进 Substance Painter 或 Blender 纹理绘制模式修细节。
6. **导出**：GLB（网页/实时）、FBX（动画/游戏）、OBJ（通用）。吉祥物网站用 GLB（小、带贴图）。

### 4.4 商用注意事项

- **版权**：AI 生成物的版权归属各平台条款不同，商用前读 Tripo 的 ToS。训练数据争议仍在，最稳妥的是"AI 出初版、人工精修到面目全非"——改到 70% 以上，法律风险趋近于零。
- **不要直接商用原图转 3D 的贴图**：如果输入图是网图，输出贴图可能带原图版权风险。用自家手绘稿当输入最干净。
- **Tripo 免费版 vs Pro**：免费版可测流程，商用上 Pro（约 $20/月，可取消）。潘熠已定"走云端 AI 转 3D，我来跑流程"，等他的 API Key。

## 五、3D 在平面设计中的应用：5 种常用技法

1. **3D 标题字**：Blender `Shift+A` → Text → 输入文字 → 挤出（Extrude）给厚度 → 倒角（Bevel）磨圆边 → 上材质打光。菜单"招牌"大字、海报标题的立体做法。注意：只用于标题，正文别碰。
2. **产品效果图**：包装盒/瓶子/礼盒建个简模 → PBR 材质 → 三点布光+HDRI → Cycles 渲染。解决"暗粒"包装盒"穿模"问题的正解——真渲染一张，比 PS 贴图强 10 倍。
3. **场景合成**：3D 渲染主体 + 平面排版背景。用渲染通道（Z-Depth/阴影）做蒙版，主体"坐"进版面里，而不是"贴"在上面。
4. **等距小场景（Isometric）**：45° 俯视小场景，信息图、流程图、KV 配图的神器。Blender 里相机设正交+45°，一次成型。
5. **3D 图标/装饰元素**：简单的几何体+好材质+好灯光，渲染出来当图标用。比扁平图标贵 10 倍的气质，成本只多 1 小时。

## 六、3D 渲染感检查清单（10 条）

看一张效果图，逐条打勾：

- [ ] **阴影是软的吗？** 硬阴影边缘=假。面光源越大越软。
- [ ] **暗部死黑吗？** 死黑=没有 GI/环境光。暗部应该带环境色。
- [ ] **金属/光滑表面有反射吗？** 没有环境反射的金属=灰塑料。
- [ ] **物体"坐"住了吗？** 接触面有没有 AO 阴影？没有=浮空=穿模感。
- [ ] **有景深吗？** 全图一样锐=假。焦点外应该渐虚。
- [ ] **材质有"脏"吗？** 100% 干净=CG 味。粗糙度贴图加一点不完美。
- [ ] **比例对吗？** 门窗/家具/产品尺寸符合现实吗？（潘熠 2026-10-13 案例审计：不可能的结构是"假"的第一根源）
- [ ] **光源方向统一吗？** 所有物体的高光/阴影指向同一个主光方向吗？
- [ ] **色温统一吗？** 暖光场景里混进冷色高光=穿帮。
- [ ] **边缘有"呼吸"吗？** 过度锐利的边缘+完美倒角=CG；真实物体边缘有微磨损（倒角+粗糙度变化）。

**10 条全过=照片级；过 7 条=可用；少于 5 条=重渲。**

## 七、本次学习的自我检查（下次做 3D 相关活之前默念）

1. 灯光：三点布光齐了吗？HDRI 加了吗？
2. 材质：PBR 四参数对吗？（金属度别乱开、粗糙度别一视同仁）
3. 真实感：接触阴影、软阴影、景深、不完美，四个至少中三个？
4. AI 3D：输入图干净吗？背面检查了吗？拓扑清理了吗？商用条款读了吗？
