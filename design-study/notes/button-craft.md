## 一、先层级，后质感：三级按钮体系

按钮的问题 80% 是层级问题，不是质感问题。质感再好，两个一级按钮并排也等于没有重点。

| 级别 | 角色 | 视觉待遇 | 本站对应 |
|---|---|---|---|
| L1 | 全场唯一主 CTA | 黏土质感全开 + 金边 + 最强阴影 | "立即开始设计" |
| L2 | 功能入口 | 保留黏土质感，但**降一级**：去金边、低对比描边、阴影减半 | 查看作品 / 免费咨询 |
| L3 | 次要入口 | 纯文字链，无质感 | 页脚/次要跳转 |

**铁律**：
1. 一屏只允许一个 L1。L1 的金边（#C6A15B）是全站最稀缺的视觉货币，花在第二处就贬值。
2. L2 与 L1 的差距必须"一眼可辨"：至少在描边对比度和阴影强度两个维度同时拉开，只动一个维度用户感知不到。
3. 每页 CTA 总数 2–3 个为宜（高转化落地页的通行做法），多了就是认知过载。

依据：designstudiouiux CTA 最佳实践（视觉对比 = Von Restorff 孤立效应）；upwardengine（60-30-10 法则，CTA 只占 10%）。

## 二、黏土质感配方（深色适配版）

本站按钮 = 黏土拟物（claymorphism）+ 暗色主题。两个流派各有坑，配方如下：

### 2.1 三层阴影结构（光源必须统一）

```
外投影：  柔光、色调匹配按钮色、透明度克制（深色底上投影天然弱，别硬加）
内高光：  inset，左上，亮色（白 40–60%，带一点按钮色相——纯白=塑料感）
内暗影：  inset，右下，深色（带色相的深色——纯黑=脏）
```

- 左上亮 / 右下暗 = 统一光源从左上打过来。**全站所有按钮同一个光源方向**，
  这是 render-feel-framework 里"不一致毫秒级报警"的直接应用——光源一乱，按钮立刻显"贴"。
- 深色模式的坑：传统深色投影在深底上会变脏或直接消失。
  对策是**用"提亮表层 + 内阴影"表现体积**，而不是依赖外投影
  （accessibilitychecker：深色层级靠提亮/elevation，不靠投影）。

### 2.2 去塑料感四招

1. 高光不纯白：取按钮色的提亮版，或白 50% 叠加色相。
2. 暗影不纯黑：取按钮色的压暗版，保留色相。
3. 大圆角（胶囊/28px+）+ 适度模糊——小圆角+硬阴影=塑料玩具。
4. 细微纹理/噪点（可选）：1–2% 的噪点是"哑光黏土"和"光面塑料"的分水岭。

依据：setproduct claymorphism 配方（三层阴影结构）；hype4.academy（双内阴影+单外投影，X 轴可微调打破呆板）。

### 2.3 三态必须肉眼可辨（hover / active / focus）

- **hover**：上浮 2px（translateY(-2px)）+ 外影加重——"浮起来，可点"。
- **active（按压）**：关键不在缩小，在**阴影同时收紧**——外影缩小变淡、
  内影加深，再配 scale(0.97) 或下沉 2px。阴影不收紧、只缩小的按钮，
  看起来像"图片被捏小了"，没有"按进页面"的感觉。
- **focus（键盘）**：独立的聚焦环（如 3px 半透明描边），不能只用颜色变化。
- 过渡 140–200ms ease；三态切换必须是"果冻感"不是"跳变"。

### 2.4 性能红线（移动端）

- blur 半径 ≤ 20–30px；`will-change` 慎用；阴影尺寸用 `clamp()` 随屏缩放。
- 95% 的效果 1–3 层阴影足够，层数多=低端机掉帧。

依据：copyprogramming 2026 按钮阴影实践。

## 三、深色 CTA 的对比铁律

1. **深色不是浅色的反转**：直接反转会洗掉层级、按钮发灰。深色 CTA
   要用**更高不透明度 + 更亮的底色**单独设计。
2. **饱和色在深底上会"振动"**（蓝/红/绿的高饱和色在深色上溢出、晃眼）——
   强调色要**略降饱和**，保留品牌识别但不刺眼。
   （本站金色 #C6A15B 本身是哑光香槟金，已经是降饱和思路，继续保持。）
3. 文字用**近白（#ECEAE4 一系）而非纯白**——纯白在深底上眩光，近白减眩光且更高级。
4. 对比度底线：正文 4.5:1，大字/按钮文字 3:1（WCAG，深浅色模式各自独立达标，
   浅色过了不代表深色过了）。

依据：designerly 深色设计实践；accessibilitychecker 深色无障碍指南；
neelnetworks 2026 深色色彩系统；digitalsilk 深色转化指南。

## 四、文案与图标：按钮的"语义层"

1. 文案 = 动作+收益，拒绝"提交/确定"式黑话。"立即开始设计"✅（动作+低门槛+收益暗示）。
2. 每个按钮配**专属语义图标**（咨询=气泡、查看=眼睛、下载/复制/发送各一）——
   图标不是装饰，是第二阅读通道；图标语义错 = 可信度打折。
3. 中英双行排版（潘熠 10-16 按钮规范）：中英文居中、等宽；宽=中文+两侧 padding；
   高=双行+padding；44px 最小触控。英文线降级处理——更细、更小、更低对比，
   是中文的装饰回声，不是并列标题（10-15"英文不要喧宾夺主"）。
4. 图标与文字的间距固定为字号的 0.5×，全站统一。

## 五、返工验收清单（逐项打勾，报完成前自查）

- [ ] 眯眼测试：第一眼落在 L1 上，L2/L3 依次退后
- [ ] 转黑白截图：层级依然清晰（明度对比自检）
- [ ] hover / active / focus 三态录屏可辨，无跳变
- [ ] 全站按钮同一光源方向、同一半径体系、同一过渡时长
- [ ] 金边只出现在 L1；L2 描边 ≤ 白 15% 透明度
- [ ] 按钮文字对比度 ≥ 3:1（深色模式实测，非估算）
- [ ] 移动端 390px：无溢出、触控区 ≥ 44px、阴影不糊
- [ ] 按压态是"塌下去"（阴影收紧）不是"缩图片"（只有 scale）

---

## 六、一句话总结

> 按钮的高级感 = **层级（一眼分出主次）** × **光影（三层阴影+统一光源）** ×
> **材质（去塑料感的色相阴影）** × **反馈（三态果冻感）**。
> 四项缺一项，用户说不出哪不对，但就是觉得"不够高级"——
> 和"贴上去 vs 长出来"是同一条"不一致探测器"在报警。
