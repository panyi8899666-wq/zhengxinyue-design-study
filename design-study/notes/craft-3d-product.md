# 标准卡 · 3D 产品设计与生产

> 一句话定位：从概念草图到量产的完整工艺链速查（广告展示道具 / IP 摆件 / 包装结构 / 标识立体字 + 消费品外壳原型）——选工艺先看数量、再看精度 / 外观；模具只应在设计完全验证后再开。
> 口径标注：= 打印服务商 / 工厂 / 设备商公开技术页（嘉立创 JLC3DP、Xometry、Formlabs、Hubs/Protolabs、RpProto 等），可对客引用但注明「以具体工厂报价单为准」；= 国内手板厂 / 广告制作通行经验值，无统一国标，不同工厂浮动 ±30–50% 很常见；= 见第三节，待 pan 拍板。金额：公开来源多为美元，原样保留（1 USD ≈ 7.1 元粗换，仅作量级感）。查阅日期 2026-10-20。

## 一、选型速查（先看这张表就能接咨询）

| 数量 | 塑料件首选 | 金属件首选 | 逻辑 |
|---|---|---|---|
| 1–5 件 | 3D 打印 / CNC | CNC / 金属打印 | 无模具费者胜 |
| 10–50 件 | 硅胶复模（要外观 / 装配像量产）或 SLS/MJF 直打 | CNC | 复模单套模寿命 15–25 件，要算重做模 |
| 100–500 件 | MJF/SLS 直打 vs 铝模注塑比总价 | CNC / 钣金 | 交叉点按件算，不背死数 |
| 500–10,000 件 | 注塑（铝模 / P20 模） | 钣金 / 压铸（视形状） | 模具摊销开始低于打印差价 |
| 10,000+ 件 | 注塑（钢模、多腔） | 压铸 / 冲压 | 单件拼材料与周期，模具费占比趋小 |

工艺对号：1 件–50 件 → 3D 打印 / CNC；10–50 件且要「像注塑件」→ 硅胶复模；500 件起 → 注塑划算；中空瓶罐 → 吹塑；大而薄的壳 / 罩 / 托盘 → 吸塑；金属薄板壳体 / 字壳 → 钣金。
精度安全线（承诺值口径）：光固化 ±0.1–0.2 mm、SLS ±0.2–0.3 mm、FDM ±0.3–0.5 mm、金属打印 ±0.2–0.3 mm、CNC ±0.02–0.05 mm（关键面可 ±0.01）、注塑 ±0.05–0.1 mm（普通件 ±0.1–0.25）。客户问「能不能 ±0.05」，先问哪个工艺、哪个尺寸段、是否接受二次机加工。

## 二、核心参数速查

### 2.1 全流程阶段与冻结节点（确认节点必须客户签字 / 书面确认才进下一步）

| 阶段 | 交付物 | 确认节点 | 典型周期 |
|---|---|---|---|
| ① 需求 / 概念草图 | 需求单、草图 / 意向图、初步报价区间 | **A 方向确认**：造型方向、目标数量、目标单价（此节点改稿成本最低） | 1–3 天 |
| ② 效果图 / 外观设计（ID） | 效果图、CMF 表 | **B 外观冻结**：颜色以潘通 / 实物色板为准，不以屏幕色为准 | 2–5 天 |
| ③ 3D 建模（结构 / MD） | STEP 主文件 + 预览图 | **C 结构冻结（DFM 通过）**：冻结后再改 = 改版费 | 3–10 天（简单摆件 2–3 天，带装配外壳 5–10 天） |
| ④ 结构拆件 | 拆件图、装配爆炸图、BOM | 与 C 合并确认；拆件缝位置影响外观，必须给客户看爆炸图 | 含在 ③ 内，复杂件 +1–3 天 |
| ⑤ 打样（手板） | 实物样 1–3 件 | **D 手板签样**：签样件封存作量产验收基准 | 打印 1–3 天 / CNC 3–7 天 / 复模 5–10 天 |
| ⑥ 修模 / 改版 | 修订版数据 + 改版样 | 每轮单独确认改动清单 | 数据改版 1–3 天/轮；钢模修模 3–10 天/轮 |
| ⑦ 小批试产（T0/T1） | 试产样、首件检验报告 | **E 量产放行**：T1 样确认后才排量产 | 试模 1–2 次、每次 2–5 天 |
| ⑧ 量产 + 表面处理 + 装配 + 包装 | 量产件、检验记录 | 出货前抽检确认（AQL 抽样为行业惯例） | 注塑件按数量 3–15 天；广告大道具 10–25 天 |

广告展示类特殊节点：大型道具（≥1 m）多一个 **C+ 分段与安装方案确认**——分几段、接缝在哪、现场怎么拼、吊装 / 落地固定，不在图上确认现场必返工。
软件分工：参数化 CAD（SolidWorks / Creo / Fusion 等）出 STEP 与工程图，是量产交付主力；Rhino 曲面灵活但转注塑需转实体；Blender / ZBrush 出网格**不能直接开模**，需逆向 / 重构（报价要加工程化处理费）。接单先问客户文件类型：只有 JPG → 收设计建模费；网格 → 打印可直用、量产加工程化费；STEP → 直接进 DFM 与报价。

### 2.2 交付格式

| 格式 | 本质 | 颜色 / 纹理 | 单位 / 参数 | 可再编辑 | 适用交付 |
|---|---|---|---|---|---|
| STL | 三角面片网格，只有表面几何 | ✗ | ✗ 无单位（默认按 mm 约定，传错单位是经典事故） | 很难 | 3D 打印通用交付；导出弦高建议 0.01–0.05 mm |
| OBJ（+.mtl + 贴图） | 多边形网格 + 材质文件 | ✓（漏发贴图 = 白模） | ✗ | 很难 | 全彩打印、带纹理展示模型、渲染交换 |
| STEP（AP214/AP242） | 精确 B-rep 实体 / 曲面 | ✓ | ✓ | 好，可回 CAD 改尺寸拆件拔模 | **CNC、开模、注塑、钣金的指定交付格式** |
| 3MF（附） | 新格式 ZIP 包 | ✓ | ✓ | 网格级 | 现代切片常用；老工厂仍以 STL 为准 |
| IGES（附） | 老曲面交换格式 | 基本 RGB | ✓ | 差（曲面要缝合） | 逐步被 STEP 取代，能给 STEP 就不给 IGES |

实务：同一项目**双交付 STEP（存档 / 开模 / 改尺寸）+ STL（打印）**最稳，只交 STL 等于堵死后续改版；标识立体字 / 钣金件另需 DXF/DWG 平面展开或矢量轮廓。

### 2.3 3D 打印工艺对比

| 维度 | FDM | 光固化 SLA/MSLA | SLS | 金属 SLM/DMLS |
|---|---|---|---|---|
| 常用材料 | PLA、PETG、ABS/ASA、TPU、PA、PC、PEI | 通用 / 类 ABS / 韧性 / 透明 / 耐高温 / 铸造树脂 | PA12、PA11、玻纤增强 PA、TPU 粉末 | 316L、17-4PH、AlSi10Mg、TC4 钛、Inconel 718、模具钢 |
| 层高 | 0.1–0.3 mm（工业机 0.05–0.3） | 0.025–0.1 mm（Form 4 为 25–200 µm） | 约 0.1 mm（0.06–0.15） | 0.02–0.08 mm（Unionfab 标 0.035 mm） |
| 公差 | ±0.3 mm（≤100 mm）或 ±0.3–0.4% | ±0.2 mm（≤100 mm）/ ±0.3%（>100 mm） | ±0.3 mm（≤100 mm）/ ±0.4% | ±0.2–0.3 mm（≤100 mm）；精加工面可 CNC 修到 ±0.025–0.1 |
| 表面 Ra | 约 10–20 µm，层纹明显 | 约 1.5–3 µm，最光滑接近注塑外观 | 约 6–10 µm，磨砂颗粒感 | 约 3–12 µm，需后加工才光亮 |
| 强度 | 各向异性，Z 向约 XY 的 50–70%；PLA 拉伸 ≈50 MPa、ABS ≈40 MPa | 各向同性较好但通用树脂偏脆、怕紫外老化；标准树脂拉伸 ≈60 MPa 但断裂伸长低 | 近各向同性，韧性抗冲击最好一档；PA12 拉伸 ≈46–48 MPa | 致密度 >99–99.5%，接近锻件；316L 拉伸 530–650 MPa、TC4 >1,000 MPa |
| 支撑 | 悬垂 >45° 需支撑，有支撑痕 | 需支撑 + 清洗 + 二次固化，有支撑点痕 | **无支撑**（粉末自支撑），可叠层排版 | 需金属支撑，切割去除 + 去应力热处理 |
| 最小壁厚（建议） | 0.8–1.0 mm | 0.5–0.6 mm | 0.7–1.0 mm（JLC3DP 指南建议 1.0 mm） | 0.5–1.0 mm |
| 单件成本量级 | 最低：公开示例 $4–24/件；国内手掌件 PLA/PETG 多 ¥30–200 | 中：$15–60/件；国内树脂常按 ¥0.8–2.5/g 量级 | 中高：$30–150/件；国内 PA12 手掌功能件多 ¥150–600 | 最高：小件起步常见 ¥300–1,000+ |
| 交期 | 1–3 天 | 1–3 天（工业服务 2–3 天） | 2–4 天 | 4–8 天 |

适用对号：IP 摆件 / 手办母模 → 光固化（SLS 次选，FDM 毁细节）；大型道具（0.5–3 m）→ 大幅面 FDM 分段 + 拼接或泡沫雕刻 + 玻璃钢；功能原型 / 卡扣铰链 → SLS/MJF PA12（通用树脂做卡扣脆断）；透明件 → 光固化透明树脂 + 抛光喷透明漆，或 CNC 亚克力 / PC（光学级更稳）；瓶型外形样 → 光固化 / FDM 空心打（打印瓶 ≠ 可吹塑瓶）；金属小批量异形 → SLM，形状规整先比 CNC；金属件 >500 件先比压铸 / 机加总价。
价格影响因素：体积 / 克重（第一位）> 层高 > 排版利用率（SLS/MJF 满版分摊）> 后处理 > 加急费。在线平台（JLC3DP 等）上传 STL 按克重 + 工艺即时报价、无起订量 1 件可做——这是「只做一个」只在打印阶段成立的原因。

### 2.4 传统量产工艺

| 工艺 | 模具费 | 数量门槛 / 周期 | 精度与限制 |
|---|---|---|---|
| 注塑 | 试产铝模 $3,000–5,000 起；公开分档：原型档（铝 / P20）$2,500–8,000、中量产（P20/718H）$8,500–25,000、大批量（H13）$30,000–100,000+。国内：简单单腔小件钢模 ¥8,000–30,000、常规外壳模 ¥30,000–150,000、复杂多腔 / 滑块抽芯 ¥150,000+ | 推荐最低 500 件起体现规模经济；试产铝模单件 $1–5、周期 6–8 周；钢模量产（10 万+）单件可降至几美分–$1；单模次 15–60 秒 | 模具寿命：铝模 5,000–10,000 模次、P20 钢模 50 万–100 万级、H13 100 万+；材料：ABS 收缩 0.4–0.7%、PP 1.5–2.0%（便宜耐折难粘难喷）、PC 0.5–0.7%（高强透明价高）；壁厚 +1 mm 冷却时间约 4 倍量级上升，减薄壁厚是最有效降本手段之一 |
| 吸塑 / 热成型 | $2,000–20,000，比同尺寸注塑模低约 80–90%；国内石膏 / 木模 ¥数百–数千、铝模 ¥5,000–30,000 | 经济区间 100–10,000 件/年；单循环 1–5 分钟 | 片厚 0.6–13 mm（常用 1–6 mm）；公差 ±0.75–1.5 mm；只有一面是模具面、拉伸角落壁厚可薄至约一半，不能成型卡扣 / 螺丝柱 / 内扣 |
| 吹塑 | $1,000–100,000（尺寸与腔数决定）；国内普通中空件模 ¥10,000–60,000、起订多在数千–数万只 | 定制瓶：单腔铝试产模半自动可做 1 万–5 万只小单；全量产常需 50 万–100 万只才摊得平（见分歧） | 壁厚典型 0.5–3.0 mm 且分布不均；只能做中空薄壁，瓶口精度靠注吹 / 瓶坯保证 |
| 硅胶复模（真空注型） | 母模 $300–1,500 + 硅胶模 $200–800（手掌尺寸；复杂 / 大件 $800–4,500）+ 单件浇注 $15–80；国内手掌件硅胶模 ¥800–3,000、单件 ¥80–400 | 经济区间约 10–50 件；**一套硅胶模约出 15–25 件**后精度 / 表面衰减——报 50 件要按 2–3 套模计价，新手最常漏算 | 精度 ±0.15 mm 或 ±0.3%（取大）；PU 可模拟 ABS/PP/PC、透明 PMMA、软胶 Shore 30A–90A，但耐热耐老化认证不能等同量产料 |
| CNC | 无模具费；成本 = 编程装夹 + 机时（3 轴 < 5 轴）+ 材料（整坯切削利用率约 65–75%）+ 刀具 + 表面处理（阳极约 $12–20/件量级） | 1–500 件经济；>250–500 件起应与注塑 / 冲压比总价 | 常规 ±0.02–0.05 mm、精密 ±0.005–0.01 mm；公差从 ±0.05 收紧到 ±0.01 以下成本可翻倍；不适用内腔封闭 / 深窄内腔 |
| 钣金 | 激光切割无模具；简单折弯模 / 治具 $800–2,500 量级 | 1 件可做；>85–100 件后对 CNC 实体加工显成本优势（机箱类个案） | 不锈钢 / 镀锌板 / 铝板 0.5–3 mm 常用；折弯件公差 ±0.2–0.5 mm；批量 500+ 后单件显著下降 |

广告大道具补充：泡沫（EPS）CNC 雕刻 + 表面硬化 / 玻璃钢翻制是 1–4 m 道具主流路线，泡沫仅适合短期 / 室内，糊玻璃钢后户外可用多年但需定期补漆，周期常规造型 15–25 天量级；玻璃钢单件 / 小批（1–20 件）经济，只做 1 件时母模成本占比最高；树脂浇注摆件（光固化母模 → 硅胶模 → PU / 宝丽石浇注 → 彩绘）是 IP 摆件 100–2,000 件区间常见路线，单件成本主要在人工彩绘。硅胶件本身量产是另一回事：模压模 ¥3,000–10,000、LSR 注射模 ¥50,000 起，勿与硅胶翻模混淆报价。

### 2.5 表面处理（总原则：处理费通常占单件结构成本 5–20%，高端更高；耐久排序大致 模内装饰 IML / 模具蚀纹 > UV 硬化喷涂、真空电镀 + 保护层 > 丝印 / 烫金（最依赖保护层））

| 工艺 | 适用 | 耐久 | 成本与坑 |
|---|---|---|---|
| 喷漆 | 几乎所有塑料、玻璃钢、金属；手板上色、道具、摆件主力 | 中；UV 硬化漆明显更好，户外需耐候面漆 | 手板按件 ¥50–300+/色/件量级，量产按面积与色数单件数元量级；多色分色遮蔽人工陡增；打印件先打磨去层纹再喷；颜色以签样实物 / 色板为准 |
| 电镀 | 水电镀（ABS 最常用）/ 真空电镀 NCVM；金属质感按键、包装、字牌 | 中高；真空镀层薄须加 UV 保护层，水镀更厚耐磨但环保成本高 | 高于喷漆数倍；非 ABS/PC 基材附着差，「电镀级 ABS」要在注塑选材阶段就定；挂具点、局部电镀加价 |
| 水转印 | 复杂曲面全包覆（木纹、碳纤、迷彩） | 耐久几乎完全由最后汽车级清漆决定，油墨层本身极薄 | 步骤多单件高于普通喷漆，小批有起步费；大平面易拉伸变形图案，深凹处易破膜 |
| 丝印（+ 移印） | Logo、文字、刻度、面板图案；平面 / 缓曲面 | 中低：油墨层薄，靠油墨体系 + 过油保护 | 最便宜一档，单色单面量产「几毛钱」量级；制版费每色一次性 ¥数十–数百；多色套印对位、渐变差；PP 需火焰 / 底涂处理 |
| 烫金 | 纸品 / 包装、塑料件 Logo | 中低：箔层薄怕刮擦，放不常摩擦的装饰位 | 需制烫印版（一次性），单件增量低；曲面 / 深纹理面烫不实 |
| 植绒 | 礼盒内衬、首饰盒、汽车内饰、手柄、仿绒面（纤维约 0.2–2.0 mm） | 中，取决于胶与纤维锚固；劣质易掉绒、怕重刮与潮湿 | 中等，按面积 + 专色纤维，小批有开机门槛；验收做摩擦 / 胶带测试，户外与涉水慎用 |

补充：模具蚀纹 / 晒纹是模具阶段一次投入（¥数百–数千），量产单件零增量、自带哑光且最耐磨；IMD/IML 图案耐磨性最好一档，但膜片与模具开发费高，订单过万才划算。

### 2.6 结构与装配（注塑为基准）

| 要点 | 主流参数 | 为什么 |
|---|---|---|
| 壁厚 | 通用 1.2–3.0 mm 均匀壁厚；分材料 ABS 0.8–3.5、PC 1.0–3.0、PP 0.9–4.0、PA 0.8–3.0；同件壁厚变化 ≤±10–25%，厚薄过渡渐变（≤3:1）+ 圆角 | 不均 → 冷却不均 → 缩水翘曲内应力；过厚冷却时间平方级上升 |
| 拔模角 | 光面 ≥1°/侧；蚀纹 / 皮纹面 3°+（纹越深越多，经验每 0.025 mm 纹深 +1° 量级）；深筋 / 深腔 0.5° 是高风险下限 | 无拔模 → 拖花、顶白、粘模；「效果图直角外壳」是注塑第一大不可产错误 |
| 圆角 | 内角 R ≥ 0.5×壁厚，外角 R = 内角 R + 壁厚；筋根部 R ≥ 0.25×壁厚 | 尖角应力集中、充填困难、模具易崩角 |
| 加强筋 | 筋厚 40–60% 相邻壁厚，筋高 ≤3×壁厚，筋间距 ≥2×壁厚，两侧加拔模 | 筋太厚背面缩水；靠加筋而非加厚整壁增刚度 |
| 螺丝柱（Boss） | 柱外径 ≈2×螺丝外径，柱壁厚 ≈0.6×主壁厚，柱高 ≤2.5–3×孔径，独立柱用三角筋连侧壁，柱根加圆角 / 沉台 | 太单薄拧螺丝开裂（PC/PA 尤甚），太厚背面缩水 |
| 卡扣 | 导入角 30–45°，脱出角可拆式约 45°、永久式 90°；卡扣方向尽量顺开模方向，否则加滑块 / 斜顶（加钱）；材料选 ABS/PA/PP 韧性料 | 太短太厚装配断裂；倒扣方向不对模具费与周期齐涨 |
| 收缩率 | ABS 0.4–0.7%、PC 0.5–0.7%、PA 0.8–1.5%、PP 1.5–2.0%、POM 1.8–2.5% | 换材料 = 换收缩率 = 尺寸全盘偏移，量产材料必须开模前冻结 |
| 公差配合 | 注塑普通公差 ±0.1–0.25 mm，非关键尺寸不标 ±0.05；打印件配合单边留 0.2–0.4 mm（MJF 指南：装配间隙 ≥0.4 mm、一体活动件 ≥0.7 mm、胶粘另留 0.1–0.2 mm）；注塑壳体止口配合单边 0.1–0.2 mm | 公差每收紧一档，模具加工与检测成本上升一档；间隙不留是打样第一返工原因 |
| 分模线 / 顶针位 | 分模线放非外观边，顶针放 B 面，浇口避开外观面与受力点 | A/B 面要求必须在图纸上明确标出 |

不可生产错误 10 条（DFM 清单）：① 零拔模 / 倒扣直墙 ② 壁厚突变或局部实心大肉厚 ③ 尖角无圆角 ④ 卡扣 / 螺丝柱凭感觉（柱不连墙、柱对外观面）⑤ 公差全图 ±0.05 ⑥ 网格文件当量产文件（破面、非流形、壁厚为零）⑦ 超尺寸不拆件 ⑧ 材料后定（改收缩率）⑨ 表面处理后置（基材不匹配、没留挂具点、蚀纹面没加拔模）⑩ 装配无间隙、无胶水位。

### 2.7 打样费用构成与阶梯报价

打样费 6 项：① 建模 / 改模费（客户自备合格 STEP 可免；只有图片必收；国内简单件 ¥300–1,500、复杂装配体 ¥2,000–10,000+）② 材料费（CNC 坯料按整坯算，废料也算钱）③ 机时 / 加工费（层高越小、件越高越贵）④ 后处理费（**手板总价里常占 30–60%**；「白模价」与「成品上色价」可差 2–4 倍，必须问清要哪档）⑤ 装配 / 检测费 ⑥ 起步费 / 加急费（加急常见 +30–100%）。复模另加母模费 + 硅胶模费；注塑试模另加模具费 + 试模费（复杂模 ¥数千/次）。
阶梯逻辑：**单件价 = 一次性费用 ÷ 数量 + 单件变动成本**。一次性费用（建模、编程、模具、制版、治具）是降价唯一主要来源，变动成本随数量近似线性；曲线先陡后平：1→10 件单价可降 40–60%，100→1,000 件降 20–40%，10,000 件后再翻倍通常只降个位数。报价写法：给 10 / 100 / 500 / 1,000 / 5,000 五档阶梯价 + 每档注明含 / 不含模具费、表面处理、包装、运费、税——纠纷几乎都出在「含什么」没写清。

### 2.8 周期构成

| 环节 | 周期 | 可否压缩 |
|---|---|---|
| 需求确认 + 报价 | 0.5–2 天 | 客户反馈速度决定 |
| 建模 + 拆件 + DFM | 2–10 天 | 加急可压缩 30–50%（加人 / 加班费） |
| 打样制作 | 打印 1–3 天 / CNC 3–7 天 / 复模 5–10 天 | 打印可加急；复模受固化时间限制压不动 |
| 表面处理 | 2–5 天（电镀排缸 3–7 天） | 油漆干燥与电镀排产是硬时间 |
| 客户确认（签样） | 1–7 天（不可控） | 合同写「确认超时顺延交期」 |
| 改版循环 | 每轮 +2–5 天（打印）/ +5–15 天（修钢模） | 减少轮次靠前期冻结 |
| 开模（若量产） | 铝模 7–20 天 / 钢模 15–45 天（复杂 45–60 天） | 模具厂排产决定 |
| 量产 + 包装出货 | 3–15 天（按数量与后处理） | — |

一句话排期：总周期里真正「制作」常只占一半，另一半是确认与排队——这就是「工厂说 3 天、外面感觉要 2 周」的原因。

## 四、高频问答要点（5 问）

1. **打样多久**：先分清白模还是成品样（上色装配要加后处理）；区间不给死点——打印白模 1–3 天、带喷漆上色 3–7 天、CNC 样 3–7 天、复模小批 7–12 天、注塑样（含开模）3–7 周；把客户侧确认时间显性化（「确认稿今天定，明天就能排产」）；禁忌：不说「明天就能给」，加急先确认是加急费问题还是工艺硬时间（固化 / 干燥压不了）。
2. **能不能只做一个**：能，看工艺——打印 / CNC / 钣金激光切割 1 件可做（在线平台无起订量）；复模 / 注塑 / 电镀 / 吸塑「能做一个，但模具开机费一个件全摊」，给对比账（做 1 个 ¥X、做 10 个总价 ¥Y、单价降到 1/3–1/5）让客户自选；广告道具 / 摆件本就是单件定制市场，价格构成是设计 + 母模 / 雕刻 + 后处理，先对齐预期。
3. **模具费为什么贵**：拆四项——① 钢料（几十到几百公斤模具钢本身是钱）② 加工工时（CNC + 电火花 + 线切割 + 抛光 / 蚀纹，数十到数百机时按小时计费）③ 模具设计、模流分析、钳工装配、2–3 次试模改模 ④ 买的是产能不是铁块（钢模寿命 10 万–100 万模次，摊到每件几分到几毛；铝模便宜一半以上但寿命只有 5,000–10,000 次）；收尾给选择题：数量没验证前先复模 / 打印小批卖，跑通再开钢模。
4. **精度能做到多少**：先反问工艺、尺寸、关键装配面还是外观尺寸；给承诺值非极限值（光固化 ±0.1–0.2｜SLS ±0.2–0.3｜FDM ±0.3–0.5｜金属打印 ±0.2–0.3｜CNC ±0.02–0.05｜复模 ±0.15–0.3｜注塑 ±0.05–0.1 关键面）；说明百分比效应（100 mm 件 ±0.2–0.3 正常，500 mm 件谈 ±0.1 不现实）；真要 ±0.05 以内走 CNC 精加工或打印后二次机加工，价格另算，先打样实测再签量产公差。
5. **改版怎么收费**：按改在哪一层分档——数据小改（未打样前）：按工时 ¥200–800/次量级，或合同含 1–2 次免费小改（冻结确认前免费、冻结后收费须写进合同）；已打样后改版：改模费 + 重新打样费全套（打印件改版最便宜）；已开钢模后：加胶（减钢）相对易、减胶（烧焊 / 镶件）贵 ¥数千–数万、周期 +5–15 天，方向性改错（换材料改收缩）可能整模重估；CMF 改版：改色最便宜，改表面工艺涉及基材与模具蚀纹按新工艺重报。话术：「改版费不是惩罚，改动越下游已沉没的加工越多；想省改版费，就把确认做在打样之前。」

## 五、未能核实（原样保留）

- **国内手板厂实时克重单价**（光固化 ¥/g、SLS ¥/cm³）：各平台需上传文件即时报价，无公开固定价目表；本卡人民币区间为行业经验口径，下单前须以嘉立创 3DP / 魔猴网 / 工厂即时报价复核。
- **泡沫雕刻 + 玻璃钢大道具的单价与耐候年限**：检索到的中文页面多为厂商软文及 AI 生成内容，数据（密度 ≥30 kg/m³、户外多年、周期 15–25 天）仅作经验框架引用，未找到可信第三方技术页核实。
- **植绒、水转印的量化耐久指标**（摩擦次数、色牢度等级）：公开来源只有定性描述，无统一测试数据；验收建议按实物样做摩擦与胶带附着测试。
- **标识立体字按延米计价的具体单价**：随字高、材料、发光方式与安装条件浮动极大且无公开价目，未给出数字，仅给计价变量。
