# 标准卡 · 餐饮全套范围与改稿政策

> 一句话定位：餐饮「全套 / 全案设计」的项目范围界定（7 大系统约 55 项 + 899 / 2,000 元两档套餐范本）与全品类通用的设计稿修改政策（Logo 4 轮 / 物料每类 3 轮定版）——上架写详情、接单对范围、改稿对轮次，先查这张卡。

## 一、核心结论速览

1. **「全案」没有国家 / 行业统一标准包**：有卖家「Logo + VI 基础规范」就叫全案，有卖家含品牌定位、空间指导才叫全案；签约前必须逐项列交付物、方案套数、文件格式、应用场景。闲鱼详情页禁用无限定语的「全案含空间 / 含摄影 / 含商标」，推荐写「**餐饮开店视觉套餐（平面视觉全套，不含空间设计 / 摄影 / 印刷）**」。
2. **价格带分层**：电商 / 独立设计师 VI 套餐 2,000–8,000 元/套（基础 2,000–4,000 / 完整 5,000–8,000）；猪八戒头部 logo 399–999 元（499 元款近半年销量 6,450，verified live）；专业餐饮设计公司 VI 8 万元起、空间 1,000 元/㎡另计；行业指导价 VI 全套（约 100 项含手册）设计员级 20,000–35,000 元。**899 / 2,000 元卖的是「视觉套餐」**：899 = Logo + 少数高频物料，2,000 = Logo + 基础规范 + 菜单 / 门头 / 包装 / 线上各取核心项。
3. **修改次数主流中枢：免费 2–3 轮**（详见 §五）。「修改到满意为止 / 不限修改」是引流话术，真实边界 = 同方向、同版式内的微调不限，大方向推翻另计。
4. **交付顺序不可跳步**：需求表 + 参考图 → Logo 初稿选方向 → Logo 定稿 → 基础规范 → 门头 / 菜单 / 包装等延展 → 线上物料 → 打包交付。Logo 未定稿就做延展，改 Logo 必然连带返工。

## 四、最容易扯皮的 8 项（「不包含」标准写法，+ 可直接抄）

总原则：交付物清单、修改轮次、源文件归属、验收标准四项不写清，是餐饮全案合同纠纷主因。不包含清单旁必须紧跟加项价目（只写「不含、另收费」会被理解为漫天要价）。

1. **菜品摄影**（买家默认「做菜单 = 你来拍照」；调研口径：菜单摄影整本 30–50 道菜 3,000–8,000 元、单道 80–300 元、周期 5–7 个工作日——pan 2026-10-21 定版为不承接：本服务为广告设计前端，不含拍摄，不承接拍摄加项，客户自备图）——写：「本服务为设计前端，不含拍摄；菜品照片请自备，我方负责排版与必要的修图调色。没有成片的，可先用图库素材占位，上线前换成您的实拍图。」（买家照片需清晰无水印；供图深度精修为加项，见 §3.3。）
2. **文案撰写**（实证：文案公开价单列 200–500 元/篇）——写：「不含品牌命名、Slogan 创作、海报 / 菜单文案撰写与菜品描述润色。买家提供最终版文字，我方负责排版；文字错漏以买家定稿版为准，定稿后改字按修改政策计。」

5. **空间效果图 / 施工图**（实证：专业口径空间设计 1,000 元/㎡单列，指导价注明 VI 价格「不包括应用物体或场所本身的设计」）——写：「本套餐为平面视觉设计，不含室内空间设计、3D 效果图、平面 / 施工图、水电图与装修监理。门头与墙面仅交付平面排版与示意图；需空间设计请另行立项报价。」

8. **其他高频默认包含项（一句话清单，全部写进不包含）**：品牌定位 / 市场调研 / 品牌命名；菜单定价顾问；印刷打样跟色与现场安装指导；外卖平台代运营 / 代上架（我方只交图，上架由买家操作）；视频拍摄剪辑；包装盒型结构与刀版开模；商场 / 城管报审资料；源文件之外的「全部初稿 / 未选中方案」版权（未选中方案著作权归设计师，买断另计，经验口径）；定稿后的长期免费更新（见 §五）。

## 五、修改政策定版（全品类通用：Logo / 门头 / 海报 / PPT 美化 / 餐饮全套）

### 5.1 同行实证要点

- **头部 / 成熟卖家：免费 2–3 轮是主流中枢**。商业接单通行「含 2 轮免费修改、微调不限次、大改另计」，初稿草图 2–3 版（画星人通行说明）；台湾成熟工作室 logo / 名片通行 3 次修改；Upwork 餐饮 logo 高价档 $357/$457/$857 三档均仅 **2 次**、初稿 2/2/3 个——客单越高轮次越收敛，靠「多给方向、少给轮次」降返工。
- **低价卖家两极分化**：一极 0–1 次 + 超次明码（Upwork PPT 低价档三档均仅 1 次、额外修改 +$5/次、加页 +$5；Fiverr 额外 revision $15/次）；另一极标题打「不限修改 / 修改到满意为止」引流，正文限定同方向微调。
- **「不限」话术的真实边界（三条）**：① 限已选定方向内；② 限微调类动作（Fiverr 官方定义 revision = 改颜色、字体、大小、位置）；③ 限定稿前。任一突破（换方向、换结构、定稿后重提）同行普遍转收费。猪八戒的「修改到满意为止」是**平台保障标签**（与保证原创 / 可注册 / 不达标必赔 / 中途不加价并列），不是逐店写明的轮次。
- **品类差异**：单张物料（海报、门头、PPT 美化）同行多给 2–3 轮；PPT 按页计的低价单常见 1 轮 + 加轮收费；餐饮全套按**品类 / 阶段分别计轮**，不写全包一个总数。PPT 高价档（$100/$200/$500）三档 Unlimited，靠高客单覆盖成本。
- **超次收费实证锚点**：Fiverr $15/次、Upwork PPT 低价档 $5/次；国内合同范本：选定后重大返工 500 元/次、改名类重大改变加修 1,000 元、买断第二稿加收全款 50%、收到稿 10 日内未提修订视为默认完成。

### 5.2 关键定义

- **一轮 = 一次集中反馈**：买家一次性集中提交的全部修改意见（一条汇总消息 / 一份文档）= 一轮，卖家据此交付一版修改稿该轮即完成；零散追加的意见卖家有权合并至下一轮。无记录时双方记忆的轮次差通常有 2–4 轮（教研经验区间）——解法：集中汇总 + **版本记录表**（日期 / 修改项 / 类型 / 计入轮次 / 状态，五列）逐轮留痕。每轮反馈限 48 小时内提完（餐饮全套 72 小时），逾期未提视为该稿确认。合同应写清三个数字：版本数、轮次（含超轮次每轮多少钱）、周期；并指定**单一拍板人**收口意见。
- **微调 vs 重做判定**：微调 / 细节性 = 不动主体、构图、结构、信息层级、不新增交付物（调色、换字 / 改文案、挪位置、缩放元素、换买家提供的图、Logo 细节描边间距优化、PPT 同版式换色换图）→ 计入当前轮次不另收费、轮内条数不限（集中提交）；方向性 / 重做 = 推翻**已确认**的方向层（换风格、换构图、Logo 换全新图形、菜单换整套版式、PPT 换整套模板风格、海报换创意概念）→ **不计入原轮次，按新增 / 重做另行立项报价，先报价确认再动手**；反复性（同一处同一问题第 3 次出现）→ 暂停计轮、先回溯对齐标准（让买家在历史版本中指认最接近版）。
- **需求变更界定**：合同范本把「因买家原因更改名称」明列为重大改变保留加修权（1,000 元）；由客户新信息引起（换卖点、换渠道、换决策人）的改动定性为**需求变更**而非返工。范本采用：下单确认单上的**店名、业态（品类）、目标客群 / 价位、门店尺寸**四要素任一在开工后变更 = 需求变更。
- **平台判责规则层**：《消费者权益保护法》第 25 条——定作商品不适用七日无理由退货（但质量 / 与约定不符仍可主张，第 24 条）；第 26 条——修改次数、超次收费等格式条款须在**购买前**以显著方式提示，成交后补说或藏在详情长图末尾小字，争议时可能不被采信。执行层：平台按「约定 + 进度」处理（未开工全退、已交初稿部分退 / 不退定金、已定稿交付源文件后以主观不满意申请全退通常难获支持）；站外交易不受平台保护。
- **留痕七步**：① 《修改政策》全文放详情页**文字版**（不要只放图片）② 下单确认消息开工前必发、买家须回复「确认」（汇总套餐、包含项、店名 / 业态、尺寸、周期、轮次与重做定义、超次价）③ 全程只在平台内沟通，微信关键结论回平台复述 ④ 逐轮留痕（每版注明第 X 轮、改了什么、剩余 Y 轮、48 h 内集中反馈、逾期视为确认）⑤ 带水印 / 低清预览，书面确认定稿 + 确认收货后再交无水印高清与源文件 ⑥ 沉默视为确认先约后用 ⑦ 分段退款表预置进详情（未出初稿全退；已出初稿扣 30%–50% 方案费；已定稿未交源文件扣 70%；已交源文件不退设计费、可付费改稿；比例为建议值）。

### 5.3 政策范本（定版，可直接粘贴至商品详情）

> **卖点话术（放套餐标题下）**：「初稿多给 1 个方向、免费改稿多给 1 轮：Logo 共 4 轮、物料每类 3 轮，轮内微调不限条数；定稿后 7 天内改错字免费——改多少、剩几轮，每轮都有记录对账，不玩『不限次』的文字游戏。」
>
> **一、先选方向，再改细节**：1. 方案阶段：Logo 给 3 个初稿方向（全案套餐 4 个），门头 / 海报 / PPT 给 1–2 个版式方向；先选定 1 个方向，此阶段可免费换 1 次同类小方向。2. 修改阶段：在选定方向内修改——Logo 免费 **4 轮**，门头 / 海报 / 菜单 / 包装 / PPT 等每类物料免费 **3 轮**，餐饮全套按类分别计轮、互不挤占。3. 定稿阶段：回复「定稿」或超时未反馈（见三）即定稿，随后交付源文件与印刷文件。
> **二、什么算「一轮」**：你把要改的地方**一次性集中写成一条消息**发我，我改好交付一版 = 一轮。一轮内改几条都可以（调色、换字、挪位置、换你提供的图片等微调不限条数）。零散追加的意见我会合并到下一轮一起改。每交一版，我会注明「第几轮、改了什么、还剩几轮」。
> **三、反馈时限**：每版稿请在 **48 小时内**集中反馈（全套物料 72 小时）；超时未反馈视为确认该稿，计入定稿。等待反馈的时间不计入制作周期。
> **四、微调免费、重做另计**：✅ 微调（轮次内不另收费）：改颜色、改文字内容、调字号大小、挪元素位置、替换你提供的图片、Logo 细节优化。❌ 重做（不算修改，按新做计费、先报价你确认后再做）：换整体风格、换构图 / 版式、Logo 换全新图形、换了店名 / 换了行业、定稿后推翻已确认方向。重做按该单项价格的 5–8 折计（下单确认时会写明本单的具体数字）。
> **五、超轮次价格**：Logo 超轮次微调 50 元/轮；单项物料（门头 / 海报 / 菜单页 / PPT 等）超轮次微调 30 元/轮；PPT 加页 10 元/页起（按套餐确认单为准）。
> **六、定稿后**：定稿后 **7 天内**，纯文字纠错（错别字、电话、价格笔误，不动版式）免费改 1 次；换菜品、换活动内容、换图片等按 30 元/次起计；换版式 / 换方向按重做计。源文件交付后请自行校对再印刷，自行改动产生的问题无法由我方承担。
> **七、需求变更**：开工后换店名、换品类（如面馆改火锅）、换定位，属新需求：未出初稿可免费重填 1 次需求表；已出初稿的，Logo 按重做计、已完成物料按 5 折重排；已交付初稿的订单中途终止，按进度结算（初稿已交不低于套餐价 50%）。
> **八、确认方式**：所有确认只认本平台聊天记录。下单前我会发《下单确认单》（套餐、店名、尺寸、周期、本政策），你回复「确认」后开工。

范本设计逻辑：轮次（Logo 4 / 物料 3）比主流（2–3 轮）多 1 轮达成「适当多给」；五道护栏 = 阶段锁方向、集中反馈计轮、48/72 小时沉默确认、微调 / 重做定义表、超次与重做明码——删任何一道，「多给」就会退化成「不限」的翻车路径。
定稿口径汇总：定稿 = 买家平台聊天明确回复确认（或逾期视为确认）；源文件范围——尾款 / 确认收货后交付**定稿款**的 AI（+ 约定的一项 PSD/CDR）源文件，初稿、未选中方案、半成品默认不交付（报告范本选「定稿源文件全含、不另收费」作卖点，政策须二选一写死）。
周期口径：公开流程核心 VI 约 1–2 周（需求沟通 1–3 天 + 概念 3–5 天出 2–3 套 + 反馈优化 2–3 天 + 交付 1–2 天）；范本周期 899 档 5–7 个工作日、2,000 档 7–12 个工作日（从资料齐全 + Logo 方向确认起算，买家反馈等待不计入，须写明）。

### 5.4 「不限修改」翻车案例（实证，可引用）

1. **「改到你满意」双输案**（永灿复盘）：工业设备企业官网合同只写「设计稿修改至甲方满意为止」，首页因「感觉不对」+ 市场 / 销售 / 老板三方意见矛盾 + 反馈无时限，改至第五版仍未定，**四个月未定稿**、错过行业展会、尾款长期拖延、服务商亏损。结论：无限次修改的成本不会消失，只会换一种方式回到项目里。
2. **「Unlimited 是我们写过最糟的条款」**（DEV 社区复盘）：无限修改后客户失去决策激励、反馈零散化，项目从 2 周拖到 **3 个月以上**；改为 3 个结构化轮次 + 每轮书面具体反馈后，交付反而更快更好。
3. **差评结构性来源**（画星人教研经验）：商业插画的大部分差评、返工、纠纷、丢复购，根源不是画得不好，而是**不约定修改次数、只靠口头沟通、无书面记录、跳过草图确认直接成稿**——与电商设计单差评结构高度一致（经验口径）。

「适当多给」打法：分阶段给、越往后越收（方案阶段大方：初稿多 1 个方向、方向内可换 1 次小方向；定稿阶段收紧只微调）；轮次比主流多 1 轮但绑定集中反馈（零散碎改才是工时黑洞）；微调不限条数 + 定稿后 7 天 1 次文字纠错做卖点（成本极低、餐饮买家感知价值极高——印错电话整批报废）；把护栏写成服务承诺（「每一轮发《修改记录》对账」）而非免责声明；详情标题与首屏**绝不使用**「不限次修改到满意为止」无限定承诺，如平台自带该保障标签，必须在详情正文紧接着给出本文定义。

## 六、分歧 / 风险提示（原样保留，待 pan 拍板）

- **「全案」定义分歧**：市面卖家口径从「Logo + VI 基础」到「策略 + VI + 空间全套」跨度极大，无统一标准——本卡对策是逐项清单锚定，不与人争「全案」二字。
- **闲鱼卖「全案」措辞风险**：899 / 2,000 元若无限定语写「全案设计」，买家会按 8 万元档理解来要求（空间 / 摄影 / 商标全含），这是扯皮入口；范本已改用「视觉套餐 / 平面全套」锚定。
- **修改政策的「多给」边界**：Logo 4 轮 / 物料 3 轮 + 微调不限条数是报告建议值（比主流多 1 轮）；删掉五道护栏中任何一道（阶段锁定、集中反馈、沉默确认、微调 / 重做定义、超次明码），多给即退化为「不限修改」翻车路径。
- **平台保障标签 vs 详情定义**：猪八戒式「修改到满意为止」标签若出现在自己店铺，必须在详情正文紧接着给出定义（同方向微调满意为止、换方向属重做），否则平台会按买家对字面的合理理解判责。

## 七、高频问答要点

1. **「全套到底含不含拍照 / 印刷 / 注册商标？」**：都不含——拍照为不承接项（pan 2026-10-21 定版：本服务为广告设计前端，不含拍摄、不承接拍摄加项，菜品照片请客户自备，我方负责排版与必要的修图调色；调研口径：外包菜品摄影整本 3,000–8,000 元、数倍于套餐价，仅作成本解释之用），印刷是制作费、商标有官费与代理且无人能保证核准；详情页逐项写明「不包含」（可加项的另注加项价），买家反而觉得实在（见 §四）。
2. **「别家写不限修改，你家为什么只给 4 轮？」**：同行「不限」的真实边界是同方向微调不限、换方向另计（Fiverr 官方即如此定义）；公开案例里只写「改到满意」的合同改了 4 个月没定稿。我们给的是 Logo 4 轮（比主流 2–3 轮多 1 轮）+ 轮内微调不限条数 + 每轮记录对账——改多少、剩几轮都明明白白。
3. **「我零散想起来一条改一条不行吗？」**：不行不是态度问题，是计数问题——无记录时双方对轮次的记忆能差 2–4 轮；集中成一条消息 = 一轮，轮内多少条微调都行，这样你的 4 轮才真正够用。
4. **「定稿后发现电话印错了怎么办？」**：定稿后 7 天内纯文字纠错免费 1 次（错字、电话、价格笔误，不动版式）正是为这个场景设的；超过 7 天或要换内容按 30 元/次起。提醒：源文件交付后务必自行校对再印刷。
5. **「开工后想换店名 / 改行当（如面馆改火锅）？」**：属需求变更不是修改——未出初稿可免费重填 1 次需求表；已出初稿的 Logo 按重做计、已完成物料 5 折重排；换行业 = 新订单，已完成部分按进度结算（初稿已交不低于套餐价 50%）。
6. **「二店开业，原来的物料改个地址就行吧？」**：价格按单店单套尺寸计，二店适配按每项加项价 5 折；同一物料出第二尺寸 / 横竖版同样按加项——先写明就不算「坐地起价」。
7. **「源文件给不给？未选中的 Logo 方案能一起给我吗？」**：定稿款源文件（AI + 约定的一项 PSD/CDR）尾款 / 确认收货后全含、不另收费；初稿与未选中方案默认不交付（著作权归设计师，买断另计）——这一条必须在详情页二选一写死，不能含糊。

## 八、未能核实 / 局限（原样保留）

1. **闲鱼站内逐店轮次样本未能逐条打开核验**：闲鱼商品详情在公开网页端不可稳定检索，国内口径以猪八戒 verified live（搜索页保障标签 + 头部店详情，2026-10-20）+ 合同范本 + 成熟工作室公开 FAQ + 接单教育机构通行说明交叉得出；如需闲鱼逐店样本须在 App 内人工采样回填，数字可能与本卡区间有出入。
2. **猪八戒头部店详情正文为图片**，其「版本对比 / 修改次数」细则无法机读核验，只能确认价格、销量与平台保障标签；未把图片小字当实证引用。
3. **闲鱼 / 淘宝设计纠纷个案判责无公开统计**，§5.2 执行层为经验口径 + 法律规则层推导，不保证个案结果；金额较大时以平台介入记录与书面合同为准。
4. **美团 / 饿了么头图等平台尺寸随后台版本变动**，本卡不写死像素，采用「以买家提供的后台规格为准」写法；小红书 1242×1660 为第三方教程口径，非平台官方公告。
5. **加项价与超次价中的建议数值**为锚定实证后的电商档建议，不是市场统计均价，上架前应按自身工时复核。
6. **部分聚合站文章带营销性质**（如 canyinsheji 的公司推荐文），其价格（VI 8 万起等）仅作「专业公司口径」一项样本引用，未作行业均价。
