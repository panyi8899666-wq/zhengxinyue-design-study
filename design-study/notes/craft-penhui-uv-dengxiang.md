# 标准卡 · 喷绘 / UV 打印 / 灯箱工艺

> 一句话定位：大幅面输出三件套速查——喷绘 = 最便宜的大面积户外画面，按㎡卖布和墨；UV = 在硬质板材上直接成像，卖材料适配与小批量灵活性；灯箱 = 画面只是成本之一，型材、光源、电源、结构与安装才是报价主体。
> 口径标注：= 设备 / 材料厂家或行业平台公开资料（Roland DG、FESPA、Signapex、Mimaki、Lintel、Weldmaster 等）；= 国内加工厂通行经验值，不是国标、不是厂家承诺，下单前必须在订单里把数值写死；= 见文末分歧清单，待 pan 拍板。价格：本行业无全国统一价目，人民币价均为注明地区 / 来源的参考量级（北京、湖北县域各一例），不能直接套价成交。研究日期 2026-10-20。

# 第一篇 喷绘

> 总原则（pan 2026-10-21 定版）：生产参数不由设计方拍死：能与客户确认的先确认，客户未指定的按供应商标准。

## 1.1 机型判断：淋雨 / 暴晒超过 3 天 → 弱溶剂户外；只在室内、要近看细节 → 水性写真；两者不可互替。

| 类型 | 介质 | 精度 / 耐候 | 适用与参考价 |
|---|---|---|---|
| 户内水性（写真机） | PP 合成纸、背胶、相纸、灯片（均需水性涂层） | 高精细（文件 100–150 dpi）；不防水怕晒，行业共识只作户内 | 展厅、商场内场、会议背景、户内灯片；北京参考 30–60 元/㎡，覆膜另计 |
| 户外弱溶剂（Eco-Solvent） | 喷绘布、车贴、单透、灯布等无涂层 PVC | 文件 30–72 dpi 即可；原厂口径无覆膜户外 3 年+，FESPA：弱溶剂 / Latex 约 3 年 | 户外牌、围挡、桁架、门头、车身；北京参考 15–35 元/㎡，大幅面走量价最低 |
| 强溶剂（补充） | 同上 | FESPA：3–5 年；国内新购设备已基本被弱溶剂 / Latex / UV 卷材替代，新单不必主动推荐 | 存量老式大型户外机 |
| Latex / 树脂（补充） | 布、墙贴、车贴、纺织品 | 约 3 年；无气味可即时覆膜 | 学校、医院、餐饮等户内敏感场所兼短期户外；报价通常介于写真与 UV 卷材之间 |

主流设备幅宽：1.27 / 1.52（主流）/ 1.8 / 2.5 / 3.2 / 5 m——幅宽决定要不要拼接，报价前先问承制厂最大无拼幅宽。

## 1.2 布料（定规格必须三参数：克重 g/㎡ + 基布纱支 D + 贴合 / 刀刮工艺，缺一等于没定规格）

> **定版（pan 2026-10-21）**：喷绘布料对外正式称呼使用行内传统名称（520 灯布、550 灯布等）；克重 / 纱支 / 工艺三参数保留为内部参考注与向工厂书面确认用，不作为对外名称。（原分歧：命名解码纱支说 vs 克重说并存，见文末分歧清单第 1 条，记录保留。）

| 布料 | 主流规格 | 适用 | 价格影响 |
|---|---|---|---|
| 普通喷绘布（Frontlit） | 220–510g 均有量产；国内走量 440g（13oz）：300×500D 18×12 或 500×500D 9×9；幅宽 1.0–5.1 m；贴合工艺为主 | 桁架背景、围挡、短期户外牌 | 基准价；克重每升一档单价阶梯上浮；贴合布便宜但强度弱（涂层布约 3 倍强度），促销级贴合户外约 12 个月即老化 |
| 黑底布（Blockout） | 380–550g，中间黑 / 灰遮光层；至 1000×1000D 档 | 双面喷绘、吊挂双面、背后有旧画面 / 强光、舞台背景 | 比同克重普通布贵；双面打印再加一面打印费，勿按单面㎡误报 |
| 刀刮布（Coated） | 400–550g 主力，1000×1000D、16×16 / 18×18 / 20×20；灯箱内光刀刮可到 610–680g | 大型户外牌、高空 / 高风压、长期（2 年+）户外、灯箱内打光 | 同规格常为普通布 1.5–2.5 倍量级；抗撕裂不分层，长期项目反而省返工 |
| 网格布（Mesh） | 常见 230–340g；透风率标法不一（见分歧） | 楼体大画、围挡、脚手架、高风压区：显著降风荷载与「船帆效应」 | 布价接近或略高于普通布，省在结构（固定件不用抗风加强）；代价：画面发灰细节弱，禁近观与深色小字 |
| 软膜 | PVC 软膜厚 0.16–0.30mm，主流 0.18–0.25mm | 卡布灯箱、软膜天花、异形灯箱（见灯箱篇） | 单出画面比喷绘布贵数倍，勿与喷绘布混档 |

通用：成分约 65% PVC + 35% 涤纶；阻燃（B1/B2、NFPA701）是可选项不是默认项，商场 / 地铁 / 展馆项目订单点名阻燃等级并要检测报告。

## 1.3 文件分辨率（指成品尺寸 1:1 下有效 dpi，不是设备标称喷头 dpi——混淆这两者是出图第一大误会）

| 观看距离 | 典型场景 | 国内通行 | 海外平台口径 |
|---|---|---|---|
| <1 m | 易拉宝、展板、户内写真 | 100–150 dpi | 120–150 dpi |
| 1–3 m | 门店画面、围挡近段 | 72–100 dpi | 100–120 dpi |
| 3–10 m | 桁架背景、户外牌 | 50–72 dpi | 72–100 dpi |
| 10 m 以上 | 楼体、高炮、高速路牌 | 30–50 dpi | 50–72 dpi；巨型牌另有 20–50 dpi |

规则：30–72 dpi 的前提是观看距离 ≥3 m，3 m 以内套 30 dpi 必糊；按比例出图 dpi 须同步放大（1:10 出图、成品需 72 dpi → 文件 720 dpi）；矢量文字 / Logo 不受 dpi 限制；同级交付项：CMYK、文字转曲、拼接预留搭接。dpi 不直接计价，但高 dpi = PASS 数多出图慢，急单与近观高精（写真档）单价更高。

## 1.4 拼接（强度数据）

| 方式 | 强度 / 寿命 | 适用 |
|---|---|---|
| 热焊（热风 / 热楔 / 高频） | 接缝 **50–80 lbs/in、寿命 5 年+**，三法最强；无针孔、防水、无可见线迹 | 大画、楼体、长期户外、灯箱布——默认首选 |
| 缝纫 | **20–40 lbs/in、寿命 2–4 年**；针孔即撕裂起点，缝线先于布老化 | 无焊机时、厚重异形件、需穿绳的特殊包边；短中期项目 |
| 胶带粘合 | 最低；厂家明确不推荐户外 | 仅短期户内 |

搭接热焊常做 3–5 cm；出图时把接缝避开人脸、Logo、小字与细线，藏进大色块。拼接误差无国标：经验验收值单条接缝图文错位 ≤3 mm 不易察觉、3–5 mm 近看可见、>5 mm 一般判返工；大幅面累计尺寸误差常按边长 0.2%–0.5% 协商——合同直接写明 mm 公差 + 超差返工。超大幅面 / 异形 / 双面套准拼接人工另计，报价问清「含拼接」还是「拼接另计」。

## 1.5 安装

| 方式 | 要点 | 成本 / 风险 |
|---|---|---|
| 包边打孔（扣眼） | 四边折边约 2.5 cm 焊 / 缝加固；扣眼沿边每 2–4 英尺（约 60–120 cm）一只，国内密排常做 30–50 cm 一只 | 最便宜通用；扣眼必须打双层包边，单层必撕 |
| 拉簧 / 弹力绳 | 逐边勾挂框架 / 桁架，张力均匀可微调；优势是消皱与换画快 | 拉簧按只 / 套另计或含安装费；过疏中段鼓肚 |
| 桁架 | 20×20 / 20×30 cm 方管拼框；户外须配重 / 地锚并核算风荷载 | 报价拆三笔：画面费 ≠ 桁架租赁 / 购买费 ≠ 安装费 |
| 卡布（硅胶边卡槽） | 胶边压入铝型材槽（槽深约 12–15 mm），无外露固定件 | 胶边加工按延米另计；画面尺寸 = 型材内尺寸 + 嵌入量，量尺错 1 cm 装不上，出图前先拿型材厂画面净尺寸表 |
| 穿管 / 旗杆套 | 上下边杆套穿管悬挂 | 杆套尺寸按管径预留，订单写明 |

## 1.6 户外耐久（厂家估算多基于北 / 中欧气候，国内南方暴晒多雨引用时自动打折并写进合同）

| 组合 | 参考寿命 |
|---|---|
| 弱溶剂，不覆膜 | 约 3 年 |
| 强溶剂 / UV 墨，不覆膜 | 3–5 年 |
| 任一类 + 匹配覆膜 / 清漆 | 测试条件下可延至约 7 年 |
| 贴合廉价布料本身 | 户外约 12 个月即明显老化 |
| 水性户内画面误用户外 | 数周至数月明显褪色 / 晕染 |

覆膜作用：抗 UV 延缓褪色 + 抗刮擦 + 抗化学清洁，车贴、地面贴、长期牌必覆；劣质膜自身黄变 / 收缩会反噬画面。朝向影响：南向、倾斜 / 水平装衰减远快于北向垂直面。答「能管几年」必须三项一起报：墨水体系年限（原厂口径、温和气候）+ 布料档次 + 是否覆膜。

## 1.7 喷绘常见事故

| 事故 | 预防 | 责任界定 |
|---|---|---|
| 色差 | CMYK 出图；品牌色打样签样；同工程同机同批次一次打完 | 无签样不认色差索赔；签样留双份 |
| 褪色 | 按耐久组合选材；红色 / 品红通常先褪，大红主色主动提示 | 合同写预期寿命与气候条件，不写「保 X 年不褪色」 |
| 布面起皱 | 卷筒收纳运输（roll never fold）；拉簧均匀张拉；大画升克重 / 刀刮布；避开正午高温绷紧 | 先分清运输折痕（生产责任）还是安装张力（安装责任） |
| 拼接错位 | 接缝避敏感区；同批次布；焊前试样测收缩；按承制厂搭接参数分片 | 按合同 mm 公差验收，无约定则无据 |
| 扣眼撕裂 / 掉边 | 双层包边打孔、角部加强、高风区改网格布或加密固定点 | 户外大画先做抗风判断 |
| 尺寸做错 | 订单四尺寸分开写：安装位净尺寸 / 成品画面尺寸 / 可视尺寸 / 文件尺寸（含搭接与包边量） | 交付文件命名带成品尺寸 |

喷绘报价拆分：布料档次（贴合 < 黑背 < 刀刮）× 克重 + 打印档（户外喷绘 < 写真）+ 后道（拼接 / 包边 / 打孔 / 覆膜 / 胶边）+ 安装（桁架 / 高空 / 拉簧另列）+ 急单费；不足 1㎡ 多按 1㎡ 起算、小单设最低消费，报价时先声明。

# 第二篇 UV 打印

## 2.1 平板 vs 卷材

原理：UV-LED 光引发聚合，墨落在材料表面瞬间固化成膜、不靠材料吸收——能打玻璃 / 金属 / 亚克力的根本原因；打完即取用无需除气。固化能量过高墨膜变脆开裂、过低底层固化不足掉墨，是 UV 品控核心窗口。

| 维度 | 平板 UV | 卷材 UV / 卷板一体 |
|---|---|---|
| 代表规格 | Mimaki UJF-6042MkII：610×420 mm、介质厚 ≤153 mm、1200×1200 dpi；工业平板常见 2513、3020 | Mimaki UJV55-320：幅宽 3.2 m、介质厚 ≤1.0 mm、300–1200 dpi、60㎡/h；UJV100-160：1.6 m |
| 介质 | 硬质板材与异形件：亚克力、PVC 板、金属板、玻璃、木板、皮革（真空吸附 / 治具定位） | 膜、布、灯片、车贴膜、墙纸、软膜等卷材 |
| 选型 | 板材、厚件、异形件、小批量多品种 → 平板 | 长卷软材、大面积灯布 / 墙贴走量 → 卷材；只有卷材不要接厚板件，反之亦然 |
| 价格 | 按件 / 按张为主，治具与排版人工占比高 | 按㎡，单价数倍于弱溶剂喷绘（墨与设备贵） |

## 2.2 材料与附着力（附着力是 UV 第一质量风险：什么都能打上，牢不牢逐材验证）

| 材料 | 附着与处理 | 口径 |
|---|---|---|
| 亚克力（PMMA） | 好，通常免底漆；清洁除尘去静电；背面镜像打印 + 白墨打底是标牌常用法 | 行业经验（从业反馈印证） |
| PVC 板 / 雪弗板 / KT 板 | 好，UV 主力介质；低表面能 PP/PE 中空板易边缘剥落，需测试 / 电晕 / 底涂；表面能约 40–50 dyn 为稳定附着经验区间 | 行业经验 + 厂家实证 |
| 金属板（铝 / 不锈钢 / 铝塑板） | 中，光滑金属需底漆：擦拭型 primer 或可喷 primer（Mimaki PR-200 仅打图文区）；不锈钢镜面尤其要测；烤漆面 / 阳极氧化面与裸金属逐批测 | 厂家实证 |
| 玻璃 | 差，必须底漆 / 附着促进剂（玻璃专用 P4 类）+ 异丙醇清洁 | 厂家实证（Roland DGA 教程以玻璃状硬面为失败案例） |
| 皮革 | 中，选柔性 UV 墨（硬墨弯折开裂），先小样弯折测试 | 行业经验 |
| 木板 | 中上，未处理原木先封底 / 底漆防渗色翘曲，打磨除尘 | 行业经验 |

验收法（可写进合同）：百格 / 十字划格 + 胶带撕拉——只带走划格线内墨 = 合格，整格脱落 = 附着失败，需 primer 或换墨；任何新材料 / 新批次先百格测试 + 打样签样再批量；打印前清洁是工序不是选项。底漆计价：手工擦涂按张 / 件收人工耗材，可喷 primer 按墨路与墨量计（原厂 PR-200 为 250 ml / 1 L 体系，价格显著高于国产通用涂层）；报价单把「含涂层处理」与「不含」分开写，玻璃 / 金属单尤其如此。

## 2.3 白墨与浮雕

白墨三用法：① 打底（透明 / 深色材先铺白再 CMYK，颜色才正）；② 夹层三层打印（Color+White+Color，灯箱片 / 玻璃窗贴正反可读、昼夜发色一致）；③ 局部白作设计元素。白墨易沉淀，设备需墨循环系统；价格：白墨墨量大速度慢，铺满白底墨成本可翻倍量级，报价问清「要不要白底、白打多满」。
光油（Clear）：局部亮哑对比 / 纹理图案，兼保护层。
浮雕 / 3D 纹理：靠白墨 / 光油多次叠印堆高，常见可交付堆高约 0.1–0.5 mm；更高堆高 = 更多 PASS、速度成倍下降。参考：每 0.1 mm 层约增加 3–8 秒固化时间。浮雕按层数 / 堆高单独核价，不要用平面 UV 的㎡价接浮雕活；盲文点字有规范要求时按项目规范单独确认。

## 2.4 精度与最小字

- 设备分辨率：主流标称 1200 dpi（UJF 1200×1200、UJV 300/600/900/1200 档），桌面小平板可标 1440 甚至 2880 dpi；标称 dpi ≠ 可交付细节（受墨滴大小、材料表面、墨层厚度、白墨套准影响）。
- 文件分辨率：板材近观成品尺寸下 150–300 dpi；大幅面远观板材 100–150 dpi；矢量图文优先矢量交付。
- 最小字 / 线条（无厂家统一承诺，加工厂通行可交付经验值）：阳字字高 ≥3 mm 承诺（≥2–3 mm 可稳定再现）；阴字 / 反白字 ≥3–4 mm；阳线 ≥0.3 mm、阴线 ≥0.5 mm。（对照：UV 转印标签「字高 >1 mm」只是可读技术下限，不是交付标准。）含小字的活先打实物样看字。
- 色差：用 ΔE 管理；材料批次、白墨厚度、固化参数是三大高频色差变量——签样是唯一护身符。

## 2.5 户外耐候（承诺口径）

| 来源 | 说法 |
|---|---|
| FESPA | UV 固化墨户外 3–5 年；配覆膜 / 清漆测试可至约 7 年 |
| Mimaki 经销规格 | LUS 系列墨户外 up to 5 years |
| 行业综述 | 现代 UV 墨经 3M MCS 类认证 + 覆膜可 5–7 年；早期 UV 墨只有 1–2 年（新旧口径混杂是年限混乱主因） |
| 通俗问答站 | 无覆膜至少 2 年、覆膜 5 年+（最保守） |

落地结论（报告综合）：对客按**户外 3 年基准档、优质墨 + 覆膜 / 光油可谈 5 年**报价；超 5 年承诺必须绑定具体墨水体系认证与覆膜规格写进合同。室内寿命通常远长于户外（10 年量级说法常见），直射阳光的户内位置按户外打折。基材先于墨失效（PVC 板黄变、亚克力老化）不属于「褪色」赔付，合同分开写。

## 2.6 计价

| 场景 | 计价 | 说明 |
|---|---|---|
| 大板整张（文化墙、门牌、背板） | 按㎡（先对齐：按板材成品面积还是打印面积） | 参考量级：亚克力 UV 200–400 元/㎡；PVC 板 + UV 文化墙含设计制作安装 150–350 元/㎡——含不含板材、含不含安装，价差就在这 |
| 小件 / 异形件 | 按件 + 开机 / 版位费（setup） | 海外实例：新单 setup $250 起 + 小件 $10–25 / 中件 $45–65 / 大件 $100+/件；国内对应「开机费 / 排版费 + 件价」，小批量贵在治具定位人工不是墨 |
| 墨成本结构（理解报价用） | 仅 CMYK 约 $0.45–1.50/㎡，加白底 + 光油升至 $1.75–4.50/㎡；整机生产成本口径 $5–8 / $8–15 / $15–20+ 每㎡ | 仅用于理解「为什么加白加光油浮雕要加钱」，不可直接乘汇率当报价 |
| 加价项清单 | 白墨满底、光油、浮雕层数、底漆 / 涂层、治具定制、双面打印、异形切割、急单、来料打印废品风险（客户自带料须多备试错件） | 逐项问清 |

## 2.7 UV vs 丝印 vs 贴膜

| 维度 | UV 数字打印 | 丝印 | 贴膜 |
|---|---|---|---|
| 经济批量 | 短单占优：约 <500–1000 件综合成本可省 50–80%；平衡点通行约 500–1000 件 | 长单占优：同图数千件以上、色数少时单件墨成本最低 | 中批量平面画面；超大平面靠分块贴 |
| 色彩 | 全彩渐变、照片级、可变数据 | 专色精准、墨层厚；渐变与照片弱 | 全彩（底层仍是喷绘 / UV 卷材打印），色牢度取决于底层打印 + 膜 |
| 材料适配 | 硬质板材直打是独门优势 | 平面为主，曲面 / 异形受限 | 只能贴附平整 / 微曲表面，边角翘边风险 |
| 耐久 | 3–5 年口径 | 墨层厚，户外耐久传统上被认为更强、专色不褪 | 取决于膜等级：铸造级可达 7–10 年级、聚合级次之、压延级短期 |
| 选型结论 | 1 件起、全彩、硬板、交期急 → UV | 单 / 双色、同图大批量、要专色厚墨层 → 丝印 | 可更换 / 可移除、基材不能进打印机（墙面、玻璃、车身）→ 贴膜 |

## 3.2 光源与均匀性（无排骨纹 / 无亮斑）

光源三形态：背光源 / 直下式（模组灯条阵列在画面正后方，大画落地箱主流）；侧光源（灯条在四边内侧靠导光板铺光，薄、轻、省电，幅面越大中心越暗）；灯条 / 灯管式（直下式的工程版，检修口与散热是重点）。
均匀性硬指标：120 mm 深型材 + LED 对角 pitch 100 mm + 扩散层（2 mm 乳白亚克力 + 0.5 mm 微棱镜膜），九点法亮度 min:max = **0.74**（中心:角 ≈1.35:1）；深度 <80 mm 或 pitch / 扩散不匹配时漂移至约 **0.6**，人眼读出排骨纹。
经验法则：**pitch ≤ 箱体净光学距离的约 1.0–1.2 倍**；浅箱（<80 mm）做直下式是排骨纹重灾区，要么改侧光 + 导光板，要么加深。亮斑 = 单颗 LED 正对画面距离不足、扩散不够、画面太透、透镜角度太窄。
验收写法：合同写「点亮后正常观看距离（注明 m）无可见排骨纹、无单点亮斑；有条件时九点法测亮度，min:max 不低于约定值（如 0.7）」，并约定暗环境与正常环境光下各验一次——只写「发光均匀」四字无法验收。
色温：常用 6000–7000K 正白，品牌店按 VI 可选 4000–5000K；同批同 BIN 灯珠写入订单，防「一块黄一块蓝」；亮度不是越高越好。

## 3.3 面板材质

| 材质 | 主流厚度 | 特性 | 价格影响 |
|---|---|---|---|
| 亚克力（PMMA） | 平板 2–3 mm（小幅面）/ 3–5 mm（门头、大幅面）；吸塑原板 2–3 mm 级 | 透光率 92–93%、户外耐黄变好；冲击强度低（缺口冲击 15–30 J/m）怕开裂 | 基准档；浇铸板贵于挤出板；乳白透光板按透光率选号，选错 = 亮度均匀性全错 |
| PC（聚碳酸酯） | 2–3 mm 常用 | 透光 88–90%；冲击 600–900 J/m，约为亚克力数十倍；未涂层易黄变易划伤 | 贵于亚克力约三至五成量级；户外长期用选带 UV 涂层级 |
| 软膜（PVC 透光膜） | 0.16–0.30 mm，主流 0.18–0.25 mm | 柔性张拉、无接缝大面、透光均匀；阻燃 B1 等为可选可查项 | 见 3.1 卡布打包价 |
| 刀刮布（内光） | 440–680g | 强度高、平整、透光均匀、耐户外 | 拉布 / 户外大灯箱默认选择，高于普通喷绘布 |
| 弹力布 / 经编布（热升华） | 约 180–260g 级 | 色彩柔和，透光与挺度弱于 UV 软膜 | 便宜轻便（户内展览卡布用）；不要拿它冒充 UV 软膜报灯箱价 |

导光板（侧光专用）：亚克力 4–6 mm（激光打点 / 丝印导光点），质量决定超薄灯箱均匀性上限；订单注明厚度与打点工艺，验收暗斑才有据。

## 3.4 型材

材质：主流 **6063-T5 铝合金**；壁厚是偷工高发区（工程图纸有未注壁厚 1.2 mm 级），验收卡尺抽测、订单写明壁厚。「规格」口径混乱：报价里的「80 / 120 型材」指**型材深度**，不是正面边宽；卡布正面可视边宽常在 10–25 mm 级，订单三项（深度 / 正面边宽 / 壁厚）分开写。

| 型材深度 | 光源形态 | 典型用途 |
|---|---|---|
| 13–25 mm | 侧光 + 导光板 | 超薄灯箱（中小幅面） |
| 50–80 mm | 侧光或密排直下式 | 上墙卡布、便携展览 SEG |
| 100–120 mm | 直下式 | 落地、双面、大幅面背光墙 |
| 150–200 mm 级 | 直下式模组阵列 | 户外拉布大灯箱 |

价格：深度每升一档 = 铝材用量 + 灯数 / 电源功率同步上升；异形（圆 / 弧）弯弧或分段拼接加工费单列；户外型材优先阳极氧化或氟碳喷涂防腐。

## 3.5 电源与散热

- 电压：户内主流 12V / 24V 直流（超薄框 12V/24V、SEG 系统 24V 适配器 66–174W 多档）；24V 压降小于 12V，长灯条 / 大箱优先 24V。
- 功率余量：额定功率留 **20–30% 余量**，满载是闪烁、压降与电源早衰共同成因；总功率 = 灯条 / 模组功率 × 数量，先算再选电源。
- 散热：热量集中在灯条铝基板与电源本体；箱体不能做成全密封闷罐——户外箱在防水前提下设排水 / 透气路径，户内大箱电源优先外置或置于可开检修侧；热量加速驱动电容老化，是「用一年开始闪」的典型机理。
- 接线：长距离低压必压降（远端暗近端亮），对策分段供电 / 双端供电 / 加粗线径；接插件半插虚接是现场闪烁最常见单因。

## 3.6 户外防水与抗风

- 防水：整机 / 光源系统按 **IP65 起步**选型；IP65 管不住密封胶条老化、拼缝、进线孔——结构细节：顶面披水坡度、面板压条带胶条、电源仓单独密封、进线从底部进做滴水弯、底部排水孔、密封条可更换。
- 抗风：户外灯箱是结构工程——风荷载按安装高度、迎风面积与当地基本风压核算，立式靠底座配重 / 地脚螺栓，吊式靠吊点与建筑结构连接，必须由结构 / 安装方签责，不能用「型材加厚」代替计算。
- 价格：户外版贵在防水模组、密封结构、电源防水等级与安装（高空 / 吊装）四项，「户内价改户外」要重新核价。

## 3.7 安装与换画

| 类型 | 换画方式与耗时 |
|---|---|
| 卡布灯箱 | 最快：手掰胶边一角整幅抽出、新画压入卡槽，1 人 5–15 分钟、无工具 |
| 软膜天花 | 需专业人员 + 热风设备张拉，客户不可自换；开孔位（灯具 / 喷淋）换膜同步处理 |
| 拉布灯箱 | 登高 + 逐边卸 / 挂拉簧，大规格 2 人作业；换画 = 重新张拉调平 |
| 吸塑灯箱 | 换画 = 换整块吸塑面板（需重新吸塑），周期成本最高，下单前告知客户 |
| 超薄灯箱 | 四边框开启（卡扣翻盖）抽换，1 人数分钟；大幅面开启框易变形，尺寸上限受此限制 |

量尺：灯箱出图文件尺寸 ≠ 型材外尺寸——卡布画面 = 可视尺寸 + 四边胶边嵌入量，拉布画面 = 可视尺寸 + 拉簧包边量；先向型材 / 灯箱厂索要「画面制作尺寸表」再出图，顺序反了必然返工。

## 3.8 质保与故障

质保：SEG 厂家页常见整机 1 年、延长加价；平台采购口径称优质无框灯箱 2–5 年（LED / 驱动 / 结构）。LED 标称寿命通行 50,000 小时（每天点 10 小时约 13 年，但先坏的通常是电源）。合同拆三行写：结构 / 型材 X 年、LED 光源 X 年、电源 X 年，并写明含不含上门与高空作业费；只写「整机保 X 年」，扯皮时以最短项为准对买方不利。

| 故障 | 高频成因 | 排查顺序 |
|---|---|---|
| 闪烁 | ① 接插件半插 / 虚接（指南称闪烁首要原因）② 电源功率不足 / 满载 ③ 长线压降 ④ 驱动老化 ⑤ 调光器不兼容 | 先查插头接头 → 换同规格电源交叉验证 → 测远端电压 → 查驱动 |
| 暗区 / 暗斑 | 单条灯条 / 一段模组脱接或烧毁；导光板局部损伤（侧光式）；画面透光率不均 | 开箱逐段点亮定位；区分光源问题还是画面问题（换白画面 / 开盖直看） |
| 进水 | 密封条老化、拼缝 / 进线孔失效、冷凝水无排水路径 | 查顶缝与进线孔 → 查底部积水痕 → 换胶条补排水；进水后先断电烘干再查驱动腐蚀 |
| 色温漂移 / 局部发黄 | 不同批次灯珠混用、乳白板 / 软膜局部老化黄变、高温区材料劣化 | 同批同 BIN 前置订单；黄变件单独换，无法局部「调色」挽救 |
| 画面起皱 / 脱边（卡布） | 胶边尺寸偏小、画面裁切不足、型材槽变形 | 按型材厂尺寸表重做画面；临时可在槽内加垫条应急 |

灯箱总价构成：型材（深度 / 壁厚 / 表面处理）+ 光源 + 电源 + 面板 / 画面 + 结构安装 + 质保年限（延长质保是明码加价项）。参考打包量级：卡布 / 拉布 200–400 元/㎡、吸塑 900–1200 元/㎡、动感灯箱 1000–1400 元/㎡、超薄灯箱 1500–4000 元/套。比价前提：要求对方拆分「箱体（不含画）/ 画面 / 安装」三项，否则同㎡价无可比性。

# 分歧点清单（三篇合并，原样保留，待 pan 拍板）

**喷绘篇**
1. **「550/520」命名**：纱支解码说（500×500D / 500×200D）vs 克重说（约 550 g/㎡）并存，不同厂同名不同物 → 对策：只认克重 + 纱支 + 工艺三参数。→ **pan 2026-10-21 定版：对外使用行内传统名称（520 灯布、550 灯布等）为正式称呼；克重 / 纱支数据保留为内部参考注，不作为对外名称。**
2. **分辨率**：国内远观 30–50 dpi 够用说 vs 海外平台 50–72 dpi（10 m+）/ 120 dpi 通用标准说 → 分歧根源是观看距离与「接近看」概率，合同写明观看距离与文件 dpi 即可消解。
3. **户外寿命**：销售口径「3–5 年不褪色」 vs FESPA 气候限定口径（北 / 中欧、且覆膜测试才到 7 年）→ 引用时必须带气候与覆膜条件。
4. **拼接误差**：无国标 / 厂家统一公差，各厂验收 3 mm / 5 mm 自行其是 → 只能合同约定。
5. **网格布透风率**：30% 透风（Ultraflex 标法）、70/30 织法比、37% 孔率三种标法并存，不可直接横向比价 → 问厂要「孔率 %」检测口径。

**UV 篇**
1. **户外年限**：2 年（通俗站保守口径）/ 3–5 年（FESPA 与厂家主流）/ 5–7 年（认证体系 + 覆膜）三档并存 → 报价时绑定墨水型号 + 是否覆膜说年限。
2. **「什么都能打」话术 vs 附着现实**：销售口径「免涂层万物打印」与玻璃 / 金属必须 primer 的工艺现实冲突 → 以百格测试结果为准。
3. **标称 dpi**：1200 / 1440 / 2880 dpi 标法混杂（单向 × 双向、喷头物理 dpi 与插值）→ 比 dpi 不如比实物样的最小字与渐变。
4. **按㎡口径**：按板材面积 vs 按实际打印（墨覆盖）面积 vs 按件含 setup，三种算法同单可差数倍 → 报价单写明计价面积定义。
5. **软膜 / 灯布归属**：同一软膜画面，喷绘厂按喷绘价、UV 厂按 UV 卷材价报，价差数倍 → 先定工艺（色彩与耐久要求）再比价。

**灯箱篇**
1. **均匀性标准缺失**：无国标强制的灯箱亮度均匀度数值；Lintel 九点法 0.74 为单一厂家自测，其亦承认行业多数量值「不给测试方法即无意义」→ 合同必须自带测试方法与阈值。
2. **型材「规格」指代混乱**：深度、正面边宽、壁厚三者都被口头叫作「规格」→ 订单三项分开写。
3. **质保年限**：1 年（厂家页常见）vs 2–5 年（平台采购口径）→ 按结构 / 光源 / 电源拆分写。
4. **LED 寿命话术**：50,000 小时是光源标称寿命（L70 类口径），不等于整机免维护年限；电源通常先失效 → 报价时问电源品牌与单独质保。
5. **户外抗风数值**：厂家多只写「抗风」不给等级 / 风压值，无统一可套标准 → 大型 / 高空项目必须做结构核算并签责。

# 高频问答要点（三篇各 5 问）

**喷绘**
1. 户外选喷绘还是写真：户外弱溶剂喷绘（原厂墨约 3 年口径），户内近看水性写真；写真上户外快速褪色晕染，喷绘布进商场近看颗粒感撑不起档次。
2. 客户点名「550 布」：先反问用途（要厚挺还是耐久），再让工厂按克重 + 纱支 + 贴合 / 刀刮三项书面确认后报价；只写「550 布」的报价单交付厚度对不上无追责依据。
3. 10 米宽楼体画面 dpi：成品尺寸 30–50 dpi 国内通行，海外平台 10 m+ 给 50–72 dpi；行人可走近 3–5 m 按 72 dpi；1:10 比例出图 dpi 记得 ×10。
4. 拼接缝明显吗：热焊缝平整无针孔（50–80 lbs/in），可见程度取决于接缝位置——出图避开人脸、Logo、小字；错位验收值写进合同（如 ≤5 mm）。
5. 保几年不褪色 / 要不要覆膜：弱溶剂不覆膜约 3 年（原厂口径、温和气候），覆膜测试至约 7 年；长期（2 年+）、车贴、深色 / 大红主色建议覆膜，合同把「年限 + 气候 + 是否覆膜」写成一组条件。

**UV**
1. 玻璃直印 logo 会掉吗：玻璃附着最难，不做底漆大概率整片脱落；正规做法 = 清洁 + 玻璃专用底漆 / 可喷 primer + 百格测试 + 打样签样；潮湿常擦洗建议改贴膜或 UV 转印。
2. 加白墨和浮雕为什么贵：白墨满铺一层墨且降速，白底 + 光油墨成本数倍于纯 CMYK；浮雕靠逐层叠印堆高，按墨量和时间收费；下单前确认「白打多满、浮雕几层」再核价。
3. 最小能印多小的字：阳字 ≥3 mm、反白 ≥4 mm、线条 ≥0.3 mm（阴线 ≥0.5 mm）才稳妥承诺；再小先打实物样签样。
4. 1000 块亚克力牌 UV 还是丝印：全彩 / 渐变 / 每块不同 → UV；单双色同图上千 → 丝印反超，平衡点约 500–1000 件；两家都按「总价 ÷ 件数」报全含价再比。
5. 户外 UV 招牌用几年：优质 UV 墨不覆膜 3–5 年（厂家 / FESPA 口径），加覆膜 / 光油、非极端暴晒可谈 5 年；承诺 7–10 年的先问绑定哪个墨 + 膜认证体系并写进合同；板材本身老化不在「不褪色」范围。

**灯箱**
1. 卡布 vs 拉布选哪个：卡布硅胶边压入、无框感、1 人几分钟换画，适合户内频繁换画；拉布拉簧绷灯布，适合户外大规格。
2. 排骨纹怎么解决：直下式灯条 pitch 相对箱深太大的典型病；按成本排：加扩散 / 换低透光画面布 → 加密灯条 → 加深箱体；深度 <80 mm 直下式最易出；均匀性写进合同才可验收。
3. 换一幅画面多少钱多久：卡布最省（只出新画面、现场 5–15 分钟）；拉布登高重张拉人工单列；吸塑最贵（重做整块面板，模具还在可省模具费）；长期频繁换画第一次就选卡布。
4. IP65 为什么还进水：IP65 是实验室条件，管不住老化密封条、拼缝和进线孔；下单逐项确认顶面披水、底部排水、进线滴水弯、胶条可更换，并把进水质保判定条件写进合同。
5. 质保几年 / 5 万小时不用管吗：5 万小时是灯珠标称寿命，先坏的通常是电源和接插件；整机质保市面 1 年到 2–5 年都有，延长质保加价正常；结构 / LED / 电源三项分别写年限并问清含不含上门与高空费。
