# 标准卡 · 印刷品工艺与材质

> 一句话定位：商业印刷品（单页 / 画册 / 名片 / 手提袋 / 菜单 / 彩盒）的印刷方式、纸张、印后工艺、颜色与稿件交付全速查——选印刷方式先看印量、再看色准、再看交期；90% 的印刷事故在文件阶段就注定，交付前过印前清单。
> 口径标注：= 印刷厂 / 平台 / 软件厂商公开说明；= 从业者通行经验区间，不是国标、不是任何一家厂的承诺价，报价必须以当地、当期、具体厂家询价为准（价格信息引用超 3 个月应重新询价）；= 见第三节，待 pan 拍板。研究日期 2026-10-20。

## 一、印刷方式五维对比（核心表）

| 维度 | 专版胶印（独享一版） | 拼版胶印（合版） | 数码印刷（无版） |
|---|---|---|---|
| 色准 | 最高档：可按签样跟色、可用专色、大实地最稳 | 师傅只能取全版平均色调，厂家自述色差约 **±10%** | 单张锐利、短版一致性好；做不了真专色（CMYK / 扩展色域模拟），大实地与批次复现弱于胶印 |
| 价格结构 | 版费（四色 4 张版）+ 开机费 + 调色损耗全由一家承担，量越大单价越低 | 多家分摊，同规格大货单价最低或接近最低 | 无版费无开机费，单价近似线性 |
| 起印量 | 单页 / 卡片多在 500–1000 份以上才划算；画册多 500 本起谈 | 厂家标准阶梯量（如名片按盒、单页按 1000/2000/5000 张），低于阶梯按阶梯价收 | **1 张起**；经济区间通常数百份以内 |
| 周期 | 单页 2–3 个工作日；画册 4–7 天 | 等凑满版 / 固定截稿，常见 2–4 个工作日，错过截稿顺延一班 | 简单品当天–次日；带后道 1–3 天 |
| 适合 | 品牌色严格、专色 / 特殊纸、大批量、长期翻单 | 标准尺寸标准纸、对色差宽容、预算优先的标准品 | 小批量、急单、可变数据、多版本、打样试水 |

数码 vs 胶印分界：≤100–500 份数码总价更低；500–3000 份比价区（两边都要询价）；≥3000 份胶印明显占优。案例量级：100 张 A4 双面数码约 150–250 元 vs 胶印约 500–800 元（含制版开机）；5000 张时胶印单张约 0.4–0.6 元。解释口诀：「贵的不是印，是开机前的版和调机；印得越多摊得越薄。」
决策口诀：① 有可变数据（每张姓名 / 编号 / 码不同）→ 只能数码；② 有真专色 / 金属荧光色 → 胶印（多为专版）；③ 交期 ≤24 h 且量小 → 数码，量大又急 → 专版加急；④ 颜色是品牌资产、要跨批次一致 → 专版 + 签样留样；⑤ 先数码试水后胶印翻单 → 转胶印必须重新打样，不得拿数码样当胶印验收标准。

## 二、核心参数速查

### 2.1 纸种速查

| 纸种 | 呈色 / 手感 | 常用克重（g/m²） | 典型产品 | 价格影响 |
|---|---|---|---|---|
| 铜版纸（光面） | 色彩最鲜艳、网点最锐利，照片最好 | 105 / 128 / 157 / 200 / 250 / 300 / 350 | 单页、海报、画册内页、封面、吊牌 | 基准价，最便宜一档 |
| 哑粉纸（哑光铜版） | 颜色稍沉稳、阅读不刺眼；同克重比铜版更挺更厚 | 同上 | 企业画册、说明书、高端单页、封面 | 比同克重铜版略贵（约 +5–15%，随牌号浮动） |
| 白卡纸 | 单面涂布、挺括折痕好，正面效果近铜版 | 210 / 230 / 250 / 300 / 350 / 400 | 名片、手提袋、包装盒、卡片、菜单 | 按克重上升明显加价；同克重比铜版贵且更厚 |
| 牛皮纸 | 本色黄褐、纤维感；底色偏暗偏暖，白墨 / 浅色盖不住 | 80 / 100 / 120 / 150 / 200 / 250 | 牛皮袋、信封、吊牌、复古风菜单 / 包装 | 纸不贵，但印白印准色难，沟通成本高 |
| 特种纸 | 珠光 / 触感 / 纹理 / 色纸 / 黑卡；深色纸上 CMYK 几乎看不见，须烫金 / 白墨 / 丝印 | 常见 200–350；名片亦按 µm 标厚（象牙卡 300µm、420µm） | 邀请函、名片、证书、礼盒面纸、画册封面 | 纸价常为铜版数倍，常有最低采购量；先确认库存再定设计 |

补充：画册内页另一常用纸为双胶纸（无涂布）60–120g，呈色偏哑、易透印。

### 2.2 克重 → 产品对照

| 产品 | 封面 / 主体 | 内页 / 其他 |
|---|---|---|
| 宣传单页 | 157g 铜版 / 哑粉（主流）；128g 省钱款；200g 挺括款；低于 128g 易卷边显廉价 | — |
| 折页 | 157–200g；**不建议 >250–300g**（太厚折线爆裂） | — |
| 画册 | 封面 250–300g 铜版 / 哑粉 + 覆膜（页数 ≤16P 不能低于 300g 否则显单薄） | 内页 157g（主流）/ 128g（页多省钱，纯图册易透印，图文混排优先 157g 哑粉）/ 200g（高端） |
| 名片 | 300g（标准）/ 350g（厚重感）铜版 + 覆膜；或 300–350g 白卡 / 特种纸；400g 以上偏硬 | — |
| 手提袋 | 250g 白卡 + 覆膜（主流，承重约 5 kg 内）；200–250g 铜版（轻量）；牛皮纸 150–250g | 底部 / 袋口常加卡纸加固 |
| 菜单 | 250–350g 铜版 / 白卡 + 覆膜（防水耐擦，覆膜比克重更重要） | 内页 200–300g |
| 吊牌 / 卡片 | 300–350g 铜版 / 白卡 | — |
| 包装盒（彩盒） | 250–350g 白卡 / 单面涂布卡直印；精装盒用灰板裱糊；需盒型支撑优先 250g 以上白卡 | — |

克重每升一档：纸费按「吨价 × 克重 × 用纸量」算（157→250 约 +60%），但成品总价涨幅小于纸费涨幅；真正贵的是换纸种和加后道。

### 2.3 厚度对照（克重 ≠ 厚度 ≠ 挺度）

| 克重 | 铜版纸 | 哑粉纸 | 白卡 / 单面涂布卡 |
|---|---|---|---|
| 128g | 0.105 mm | 0.12 mm | — |
| 157g | 0.135 mm | 0.16 mm | — |
| 200g | 0.17 mm | 0.19 mm | 约 0.20–0.26 mm |
| 250g | 0.23 mm | 0.25 mm | 0.32–0.325 mm |
| 300g | 0.305 mm | 0.34–0.35 mm | 0.40–0.425 mm（同克重比铜版厚约 1/3） |
| 350g | 0.345 mm | 0.365 mm | 0.46–0.48 mm |

要点：200g 是「纸 → 卡」分水岭；同克重挺度排序（经验）白卡 > 哑粉 > 铜版；牛皮纸松厚（120g 约 0.17 mm）。客户说「要厚」时先递纸样，并问清要的是厚度、挺度还是分量感。

### 2.4 印后工艺（报价结构：总价 = 纸张费 + 印前费 + 开机 / 印刷费 + 印后费 + 损耗，普通损耗约 3–5%、复杂工艺 / 特殊纸 5–10%+）

| 工艺 | 效果 / 适用 | 成本口径 | 设计端硬约束 |
|---|---|---|---|
| 覆亮膜 | 高光、提鲜、耐磨防潮；单页、海报、封面、彩盒 | 覆膜中最便宜档，按 m² 计 | 深色易留指纹、强光反光 |
| 覆哑膜 | 低反光、高级感；画册封面、手提袋、礼盒、菜单 | 略高于亮膜 | 覆后饱和度下降约 5–10%，签样须签覆膜后样 |
| 触感膜 | 类皮肤绒感；高端封面、礼盒、邀请函 | 明显高于哑膜（膜材贵 + 损耗高） | 易划伤留指纹；后续烫金 / UV 须先测附着力；深色满版慎用 |
| 烫金 / 烫银 | 金属光泽；Logo、标题、证书、礼盒 | 版费 + 开机费 + 按面积加工费；小批量单件贵 | 正线目标 ≥0.15 mm（下限 0.1 mm）、间隙 ≥0.25 mm、字 ≥7pt（反白 ≥10pt）；避开折线；大面积实地易糊版 |
| 局部 UV | 局部高亮 / 凸起触感，与哑面成反差 | 版费 + 加工费 | 平面 UV 线 ≥0.3 mm、间隙 ≥0.5 mm、字 ≥8pt；细线 <0.2 mm 勿做厚 UV |
| 击凸 / 压凹 | 无墨立体凹凸 | 金属版费是大头 + 加工费 | 笔画 ≥0.5 mm、间隙 ≥1 mm、字 ≥10pt 中粗体；背面留反向痕，薄纸压穿、厚纸压不深 |
| 模切 | 异形轮廓、开窗、盒型刀线 | 刀模费一次性 + 加工费 | 内角圆角半径 ≥1.3 mm、刀线间及距裁切 ≥3 mm；普通彩盒模切公差约 ±0.5 mm |
| 压痕 | 预压折线，折叠不爆裂 | 通常并入模切 / 折页费 | >200g 纸折叠必压痕；深色满版折线位是爆色高危区 |
| 骑马钉 | 中缝铁丝订，可 180° 摊平；页少画册、说明书 | 装订中最便宜 | 总页数（含封面）4 的倍数、最少 8 页；上限见分歧；页码离边 ≥5 mm 防爬移 |
| 无线胶装 | 有书脊可印字；画册、标书、教材 | 高于骑马钉数倍 | 书脊 <约 3 mm 做不了（约 <80 页薄纸慎用）；订口吃掉约 3–5 mm；不能完全摊平 |
| 锁线胶装 / 精装 | 最耐用；高端画册、纪念册、礼品书 | 平装的数倍–十余倍（量级：骑马订 0.66 < 胶订 1.16 < 锁线精装 13.2 元/本，政采价仅示量级） | 精装壳面展开尺寸 ≠ 内页尺寸，须按厂模板做；重要图文避开书槽 |
| 环装（Wire-O/YO 圈） | 可 360° 翻折摊平；菜谱、台历、培训资料 | 按圈径 / 孔数计，中档 | 打孔边留安全区（经验 ≥10 mm）；可抽换页（胶圈） |
| 圆角 | 常用 R2–R10；名片、卡片、菜单 | 按件小额加价 | 稿中标明半径；边框式设计 + 圆角最易显裁切偏差 |
| 打孔 | 吊牌孔 Ø3–5 mm 常见 | 按孔 / 按件小额；异形孔并入刀模 | 孔位距边、距文字留安全距离；鸡眼扣另计 |

经验：每多一道后道约 +1 个工作日排产 + 一层损耗与套准风险；「工艺堆满」不等于高级。折页铁律：包心折内页须缩窄约 2–3 mm，风琴折各面等宽——折页稿先向印厂要折手模板，不要自己均分三等分交稿。

### 2.5 颜色管理

| 项 | 要点 | 口径 |
|---|---|---|
| CMYK vs 专色 | CMYK：照片渐变便宜快，色域有限，敏感色（橙、紫、翠绿、三色灰）易偏；专色：一色一版 + 洗机调墨，品牌色跨批次一致、可做金属荧光，数码机印不了真专色只能模拟 | 厂家实证 |
| 专色加价 | 四色加 1 专色 ≈ 加一个色组；有口径称 CMYK+2 专色（六色机）比纯四色贵约 +50%（单一来源，见 §五）；只印 1–2 色的活反过来专色比四色便宜 | 分歧 / 单一来源 |
| 指定专色三件事 | 色号（含 C/U 后缀：涂布纸 C、非涂布 U，同号呈色不同）+ 承印纸 + 验收光源（D50）；只报色号不报纸等于没标准 | 行业经验 |
| ΔE 读法 | <1 基本察觉不到、1–2 近看可辨、2–5 明显递增、>5 一眼看出；数字打样国标体系（GB/T 17934.7-2021 / ISO 12647-7）：平均 ΔE00 ≤2.5、最大 ≤5.0 | 厂家实证 |
| 色差成因 | 屏幕发光 vs 纸面反光色域差；纸会改色（非涂布更暗更糊）；覆膜再改一次；观察光源不同（同色异谱） | 厂家实证 |
| 数码打样 | 模拟印刷效果，当天–1 天、数十元级；确认版式文字与大致颜色；看不出烫金 / UV / 覆膜与特种纸真实呈色 | 行业经验 |
| 上机打样 | 正式机 + 正式纸墨实印，2–5 天、数百–数千元级；确认真实呈色、专色实墨、套准、大实地 | 行业经验 |
| 必须打样 6 情形 | 品牌专色 / 敏感色或客户称「必须一模一样」；特种纸 / 深色纸 / 牛皮纸；含烫金 / 击凸 / UV / 模切；大货量大单价高；新客户新品首次合作且长期翻单；包装盒必须先做白样（结构样）验证盒型尺寸装配 | 行业经验 |

### 2.6 稿件交付规范

| 项 | 标准 | 口径 |
|---|---|---|
| 出血 | 四边各 3 mm（成品长宽各 +6 mm 做稿）；由来：裁切漂移约 0.8–1 mm；例外（名片 1 mm、卡证 1.5–2 mm、标签高精度模切 4 mm、大幅面 / 裱糊 3–5 mm）见分歧 | 厂家实证（Adobe：0.125 英寸为标准出血） |
| 安全边距 | 重要文字 / Logo / 页码距边 ≥5 mm 推荐（≥3 mm 为下限）；贴边等距边框最危险，非用不可距边 ≥5 mm 并声明误差可见性 | 厂家实证 |
| 分辨率 | 位图成品尺寸下 300 dpi；线条图 1200 ppi；有效分辨率 = 原图 dpi ÷ 放大倍数，72 dpi 网络图直印必糊 | 厂家实证 |
| 文字 | 交付前全部转曲（或字体 100% 嵌入），源文件未转曲版自己留档；最小字号：正字 ≥6pt、反白字 ≥8pt（非涂布 ≥9pt） | 厂家实证 |
| 黑色 | 小字 / 细线 / 条码 = 单黑 K100 + 叠印；条码只能 K100（底纯白）；大面积黑实地 = 富黑 C60 M40 Y40 K100（总墨 240%，配方见分歧）；总墨量 ≤300%；严禁 400% 四色黑与套版色当黑；白对象绝不叠印 | 厂家实证 |
| PDF/X | 现代默认 PDF/X-4（活透明、ICC 管理色）；厂家设备老或明确指定时用 X-1a（兼容最稳）；共同要求：字体嵌入 / 转曲、出血写入文档设置、1:1 单页输出、工艺层用专色命名并标注叠印；是否带裁切标记各厂不一，导出前问厂家 | 厂家实证 |

印前检查清单（交付前逐项打勾）：① 尺寸页数单双面与订单一致、骑马钉页数 4 倍数 ② 出血 3 mm 且背景铺到出血外缘 ③ 文字距边 ≥5 mm、无贴边边框 ④ 全文件 CMYK、无 RGB、无套版色 ⑤ 位图 ≥300 dpi、Logo 矢量 ⑥ 文字转曲 + 另存未转曲源文件 ⑦ 黑色分治、总墨 ≤300% ⑧ 黑字叠印、白对象不叠印、透明效果按厂家要求 ⑨ 工艺文件各建专色层、线宽间隙达下限、避开折线订口 ⑩ 折页按折手模板、画册按阅读顺序单页出 PDF ⑪ 专色注色号 + C/U + 纸张、敏感色附实物色样 ⑫ 导出 PDF/X-4 并用输出预览复查分色 / 总墨 / 叠印。

### 2.7 周期与急单

| 方式 / 产品 | 标准周期（文件确认无误起算，不含物流） |
|---|---|
| 数码简单品（单页 / 卡片 / 小册） | 当天–1 个工作日；带覆膜 / 装订 1–2 天 |
| 拼版（名片 / 单页 / 海报） | 2–4 个工作日（受截稿班次制约） |
| 专版单页 / 卡片 | 2–3 个工作日 |
| 专版画册（胶装） | 4–7 个工作日；精装画册 7–12 天；书刊类有 7–15 天口径 |
| 包装盒 / 手提袋（模切 + 糊合） | 5–10 个工作日；刀模新开 +1–2 天，每加一道外发工艺再 +1–2 天 |
| 打样 | 数码样当天–1 天；上机样 2–5 天；签样后才起算大货 |

急单五路径：① **数码替代胶印**（溢价经验分档：数百份内约 1.5–3 倍量级，上千份 3–5 倍以上且质量取舍变大；取舍：无真专色、大实地弱、厚纸 / 特种纸选择少）② 同工艺加急（加急费约 +30%，书刊 7–15 天可压到约 5 天，仅作谈判参照不能替厂家承诺）③ 砍工艺保交期（去烫金 / 击凸 / 异形模切，精装改胶装、胶装改骑马钉须页数合规）④ 拆单先行量（数码出应急量、胶印续大货，两批呈色纸感有差不混发比对）⑤ 同城交付（专车 / 跑腿省 1 天物流）。
同城快印边界：适合数十–数百份标书 / 讲义 / 会议资料 / 应急名片 / 打样；不适合千份以上大货、品牌色专色件、需烫金击凸异形模切精装的件、厚卡特种纸大实地——「快印解决有没有，印刷厂解决好不好和便宜不便宜」。

### 2.8 常见事故与设计端预防

| 事故 | 预防 |
|---|---|
| 色差客诉 | 建档即 CMYK；敏感色上专色或先打样；签覆膜后实物样并留样；订单写明「以签样为准 / ΔE 范围」；拼版单事先书面告知 ±10% |
| 拼版串色 / 邻版干扰 | 敏感色稿件直接转专版；拼版避免四色黑、总色值约 10–250、三色灰改单色 K 灰（不偏色） |
| 纸张开裂 / 折线爆色 | >200g 必压痕再折；深色满版避开折线或折线位留浅 / 留白；折页克重 ≤250g 为宜勿上 300g+；选顺丝缕方向；覆膜后厚卡压痕更易爆线，须先做折样 |
| 烫金对位偏差 / 糊版 / 掉金 | 线宽字号守 2.4 下限；烫金图与印刷图留容差、勿严丝合缝套准；避开折线 / 压痕线；验收按签样不按零偏差 |
| 裁切误差 / 边框歪斜 | 出血 3 mm + 安全边距 5 mm；不用贴边细边框；双面正反套准元素不设计成必须严丝合缝 |
| 小字发虚 / 四色黑彩边 | 文字细线条码一律 K100 + 叠印 |
| 胶装掉页 / 书脊问题 | 薄册改骑马钉或环装；订口预留 3–5 mm；跨页图避开人脸 / 关键物过订口 |
| 骑马钉页数 / 爬移 | 页数凑 4 倍数（加版权页 / 空白页）；页多改薄纸或胶装；页码离边 ≥5 mm |

## 四、高频问答要点（10 问）

1. **印出来和屏幕不一样**：屏幕发光（RGB）、纸面反光（CMYK），鲜艳蓝绿橙必然收敛，纸和覆膜还会再改一次；解法只有文件按 CMYK 做、品牌色用专色、印前签实物样。不说「尽量调」，说「按签样追，签样就是验收标准」。
2. **能不能便宜**：先拆价（纸 / 版开机 / 印刷 / 后道 / 损耗），再给三个真降本杠杆——降一档克重或换铜版、砍一道后道、加量摊薄固定费或改拼版（代价：不能跟色、±10%）；用「换规格」换价格，不无条件降价。
3. **多久能拿到**：拆三段报——打样确认 X 天（不计入大货）+ 生产 X 个工作日 + 物流 X 天，起算点是「文件确认无误 + 签样」之日；给标准交期与加急交期两个数让他选。
4. **急单 / 明天就要**：先问清明天必须到手的数量（往往不是全部）；先行量数码同城出、余量胶印续，或全单数码（先说清倍数与无专色 / 纸张选择少的取舍），或砍工艺保专版加急；取舍和倍数说在前面。
5. **量越多越便宜 / 200 份为什么贵**：贵在固定费（制版、开机调机、调色损耗）与数量无关，摊的人少；小批量正解是拼版或数码，不是厂家黑。
6. **打样为什么收费 / 能否不打样**：数码样是设备纸墨调色成本，上机样约等于一次小生产；可以不打但风险书面化——无签样则按「行业常规范围」验收，色差争议没有裁判；打样费是返工费的零头。
7. **克重越高越好吗**：克重 ≠ 厚度 ≠ 挺度（同 300g 三种纸厚差约 1/3）；太厚带来折裂、装订难、运费涨；递纸样，按验证过的搭配选（名片 300–350g、内页 157g、手提袋 250g 白卡）。
8. **烫金 / UV / 击凸都加上显高级**：每道工艺 = 一笔版费 + 一道工序 + 一天量级排产 + 一层套准风险，还互相干扰；给全工艺版与单工艺版两案对比看价差效果差再选，高级感来自「做准一道」。
9. **Word / 手机图 / 网图能印吗**：能处理 ≠ 能印好——RGB、72 dpi、无出血、字体缺失四件事先改，位图放大无效；给客户印前清单简版，改稿费提前说清；实在只有低清图就缩小成品尺寸或明确「按现有素材效果验收」。
10. **上次印的这次颜色不一样**：不同厂设备、纸批次、拼版班次位置都不同，同厂翻单也要凭留样追色；保留上次成品实物寄厂作色样、翻单优先原厂原工艺、品牌色改专色建档；只凭记忆 / 照片比色任何厂都不敢承诺。
