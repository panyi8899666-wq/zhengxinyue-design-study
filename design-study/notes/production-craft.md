## 一、标识牌材质：六种板材

### KT 板（泡沫板）
- **原理一句话**：PS 发泡芯两面覆纸，最轻最便宜的硬质展板。
- **视觉效果**：平整、轻薄，适合高清画面，室内看很精致。
- **成本档次**：最低。5mm 一张 1.2×2.4m 国产几十块钱。
- **适用场景**：室内短期——展会、商场促销、会议背景、打卡位。
- **设计注意**：
  - 怕水怕晒，户外用等于一次性——给客户的室外牌子永远别选 KT 板。
  - 边角易磕碰起毛，设计时重要内容离边 ≥15mm。
  - 商场/展馆用的要 B1 阻燃等级，普通 KT 板不阻燃。

### PVC 板（雪弗板/安迪板）
- **原理一句话**：PVC 发泡硬板，KT 板的"硬汉版"——防水、防潮、不变形。
- **视觉效果**：表面细腻，丝印/UV 打印适性好，颜色正。
- **成本档次**：低~中。3~10mm 常用，比 KT 板贵 2~4 倍，但耐用得多。
- **适用场景**：室内中长期标识、门牌、科室牌、商场导视；可短期户外。
- **设计注意**：
  - 厚度 5mm 以上才有挺度，大牌子（>1m）用 8~10mm 或加背衬。
  - 可雕刻镂空——做异形牌、立体字底板时优先考虑。

### 亚克力（有机玻璃）
- **原理一句话**：PMMA 透明/半透明板材，塑料里的"玻璃"。
- **视觉效果**：透光、高档，抛光边缘有水晶感；可做灯箱面板、立体字面板。
- **成本档次**：中~高。纯新料比再生料贵约 40%，再生料发黄快。
- **适用场景**：高档门头字面板、灯箱、形象墙、奖牌。
- **设计注意**：
  - 脆——大面积亚克力灯箱要考虑抗风压，厚度/龙骨要跟上。
  - 发光字面板用纯新料，再生料半年发黄客户会回来找你。
  - 雕刻边缘抛光才有水晶感，毛边=廉价。

### 铝塑板
- **原理一句话**：两层铝皮夹 PE 芯，标准 1220×2440mm，3~6mm 厚。
- **视觉效果**：平整挺括，金属底，喷漆/贴膜/UV 打印都行，是门头招牌的"标准件"。
- **成本档次**：中。户外招牌性价比之王。
- **适用场景**：户外门头底板、店招、大型墙面招牌。
- **设计注意**：
  - 标准板 1.22×2.44m——设计门头时按这个模数走，超宽要拼接，拼缝位置提前规划（藏在文字/图形后面）。
  - 涂层分 PE/PVDF，PVDF 耐候更好，户外长期用选 PVDF。
  - 折边包边处理，毛边外露会割手+显糙。

### 不锈钢
- **原理一句话**：201/304 不锈钢板，拉丝或镜面，金属字和高端包边的主力。
- **视觉效果**：拉丝=现代简约，镜面=精致高档，本身就是一种"质感设计"。
- **成本档次**：高。304 比 201 贵约 30%，但 201 在海边/潮湿环境会锈。
- **适用场景**：高档门头字、企业 logo、长期户外标识。
- **设计注意**：
  - 厦门/漳州靠海——户外不锈钢字指定 304，201 一年就锈，返工比差价贵得多。
  - 镜面不锈钢白天反光强烈，字太小会晃眼看不清。

### 木质
- **原理一句话**：实木/多层板/密度板，雕刻或镂空，温度感最强的材料。
- **视觉效果**：自然、手工感，适合文创、茶馆、民宿、日式餐饮。
- **成本档次**：中~高（看木种和工艺）。
- **适用场景**：室内文化感招牌、包厢牌、文创店。
- **设计注意**：
  - 户外用必须做防腐防潮处理，否则开裂变形。
  - 木纹方向影响观感，设计稿标注一下纹理走向。

### 材质选择速查

| 场景 | 首选 | 备选 |
|---|---|---|
| 室内短期促销 | KT 板 | PVC 3mm |
| 室内长期（门牌/导视） | PVC 5~8mm | 亚克力 |
| 户外门头底板 | 铝塑板 | — |
| 高档发光字 | 不锈钢+亚克力面板 | 树脂字 |
| 文创/餐饮个性店 | 木质/不锈钢拉丝 | — |

## 二、发光字：六种主流

### 树脂字
- **原理一句话**：液态树脂浇铸成型，固化后透光均匀，立体感强。
- **视觉效果**：字面饱满、光色均匀细腻，白天看是精致的立体字，晚上发光柔和。
- **成本档次**：中高。材料排序：不锈钢字 > 树脂字 > 迷你字 > 亚克力字。
- **适用场景**：商场内店招、品牌专柜、近距离观看的高端门头。
- **设计注意**：树脂有一定流动性，**笔画太细（<15mm）容易断胶、透光不均**——小字号别用树脂字。

### 冲孔字（外露灯字/点阵字）
- **原理一句话**：金属字壳上冲孔，每孔装一颗 LED 灯珠，灯珠直接外露。
- **视觉效果**：夜间亮度最高、穿透力最强，远看一串光点很有气势；近看灯珠颗粒感明显，不如亚克力细腻。
- **成本档次**：大尺寸时性价比最高（同样 10 米大字，冲孔比亚克力便宜得多）。
- **适用场景**：楼顶大字、高空招牌、远距离识别（高速路旁、商业综合体顶部）。
- **设计注意**：
  - 观看距离 <5m 别用冲孔——灯点颗粒感会暴露。
  - 字体选粗壮的，细笔画冲孔后结构强度不够。
  - 灯珠间距影响均匀度，间距大省钱但远看有"麻子感"。

### 背打光字（背光字）
- **原理一句话**：光源装在字背面，光打到墙上形成一圈光晕，字本身不透光。
- **视觉效果**：轮廓光、高级感、氛围感强，白天是金属字、晚上字浮在光晕上。
- **成本档次**：中。不锈钢背发光是经典款。
- **适用场景**：企业前台、文化墙、高端餐饮/酒吧/咖啡馆、深色背景墙。
- **设计注意**：
  - **墙面必须是深色/能反光的**——白墙上光晕看不见，等于白做。
  - 字离墙 3~8cm，太近光晕出不来，太远光散了。
  - 电源藏哪提前规划，背光字最怕看到拖出来的电线。

### 迷你字（高分子发光字）
- **原理一句话**：CNC 雕刻的高分子亚克力字壳，内置 LED，光效均匀。
- **视觉效果**：小巧精致、边缘细腻，近看质感好。
- **成本档次**：中。比树脂字便宜，比普通亚克力字贵。
- **适用场景**：美业、甜品店、奶茶店、商场橱窗——近距离、重精致的场景。
- **设计注意**：**字高 <10cm 的小字用迷你字**，大字用迷你字成本爆炸且没必要。

### 无边字
- **原理一句话**：去掉金属围边，正面亚克力与底板精密粘合，边框极窄。
- **视觉效果**：通透、轻盈、极简现代，没有传统发光字的"边框感"。
- **成本档次**：中高（粘合工艺要求精度）。
- **适用场景**：奶茶店、买手店、现代简约风门头。
- **设计注意**：无边=无遮挡，内部 LED 排布不均会直接透出来——对光源均匀度要求最高，找靠谱工厂。

### 平面发光字 / 铁皮字
- **原理一句话**：铁皮/镀锌板字壳 + 亚克力面板 + LED，最经典的性价比方案。
- **视觉效果**：中规中矩，发光均匀，白天看是普通金属字。
- **成本档次**：低。预算有限时的默认选项。
- **适用场景**：普通沿街店铺、小餐饮、临时/过渡性门头。
- **设计注意**：铁皮会锈——户外用必须烤漆/镀锌处理好，否则一年锈水流满墙。

### 发光字选择速查

| 场景 | 首选 |
|---|---|
| 楼顶大字/远距离 | 冲孔字 |
| 高端商场店招 | 树脂字 / 迷你字 |
| 企业前台/文化墙 | 不锈钢背打光字 |
| 奶茶/轻食现代风 | 无边字 |
| 预算有限沿街店 | 平面发光字（铁皮字） |

### 发光字避坑（行业经验）

1. **坏的第一元凶是电源和防水，不是灯珠**。雨水从灯孔、接缝、进线口渗进电源盒→短路→烧灯珠。下单必问三句：电源防水吗？接线口密封吗？安装打胶吗？
2. **报价差一倍，差在看不见的地方**：304 还是 201 不锈钢、新料还是再生亚克力、品牌 LED 还是杂牌（价差 2~3 倍）、含不含安装和售后。
3. **售后写进合同**：行业质保一般 1~2 年，敢保 3 年的工厂通常真有底气。门头是带电的户外设备，售后是质量的一部分。
4. 计价方式：按字大小"按公分"最常用，大型楼顶字"按米"，标准件"按套"。

## 三、印刷工艺：四种

### 写真（户内高精度）
- **原理一句话**：高精度喷墨打印机（1440dpi 级），水性/弱溶剂墨水，打在背胶、PP 纸、相纸、灯片上。
- **视觉效果**：色彩细腻、层次丰富，近看经得起推敲。
- **成本档次**：中。比喷绘贵（精度和墨水成本）。
- **适用场景**：室内——海报、X 展架、商场灯箱片、 cultural wall 画面。
- **设计注意**：
  - 只做室内——水性墨水见水就化、见晒就褪。
  - 做文件用 CMYK，黑色用 C70M70Y70K95（单 K100 印出来发灰还有条纹）。
  - 大红 M100Y100、深蓝 C100M80——记住这几个"安全色值"，不会偏。

### 喷绘（户外大幅面）
- **原理一句话**：宽幅喷绘机（5 米幅宽），油性/溶剂墨水，喷在灯箱布（刀刮布/520 布）上。
- **视觉效果**：远看鲜艳醒目，近看精度粗糙（墨点可见）。
- **成本档次**：低。户外大画面的默认选项。
- **适用场景**：户外广告牌、围挡、楼体大字背景、帐篷。
- **设计注意**：
  - **油性墨有刺鼻异味**——只能放通风处，商场里、室内的活别用喷绘。
  - 精度低是"特性"不是"缺陷"——户外大画面观看距离远，粗糙看不见。但**小字（<5cm）别放喷绘稿上**，糊成一团。
  - 拼缝：超 5 米要拼接，拼缝藏文字/深色后面，设计时预留。

### UV 打印（平板直喷）
- **原理一句话**：UV 墨水喷到硬质板材上，紫外灯瞬间固化，即打即干。
- **视觉效果**：墨层厚实、耐刮擦，色彩饱和，可在 KT/PVC/亚克力/金属/木板上直接打印。
- **成本档次**：中高（设备贵），但省了覆膜钱。
- **适用场景**：硬质标识牌直接成像、亚克力字面板、金属铭牌。
- **设计注意**：
  - 白墨是关键——深色板上印彩色要先打白底，否则颜色发暗。跟工厂确认"打不打白"。
  - 户外耐候 3~5 年，比写真强得多。
  - 可做浮雕/光油堆积效果（厚墨）， logo 想做触感时问工厂。

### 丝印（丝网印刷）
- **原理一句话**：网版漏墨，一色一版，适合大批量、少色数。
- **视觉效果**：墨层厚、遮盖力强、颜色实，专色准。
- **成本档次**：制版费高摊薄——100 件以下别碰丝印，1000 件以上单价碾压数码。
- **适用场景**：大批量单色/少色印刷——手提袋、文化衫、不干胶标签、亚克力标牌量产。
- **设计注意**：
  - 一色一版——**颜色越多制版费越高**，设计稿先数颜色，4 色以上不如走数码。
  - 渐变、精细网点是丝印的弱项，大面积渐变容易断层。
  - 专色（Pantone）是丝印的强项——品牌标准色大批量印，丝印比数码准。

### 印刷工艺选择速查

| 场景 | 工艺 | 原因 |
|---|---|---|
| 室内海报/灯箱片 | 写真 | 精度高、色彩好 |
| 户外大画面 | 喷绘 | 便宜、幅宽大、耐候 |
| 硬质板直接成像 | UV 打印 | 即打即干、耐刮、不用覆膜 |
| 大批量少色 | 丝印 | 单价低、专色准 |
| 小批量多色 | 数码/写真 | 无制版费 |

## 四、表面处理：四种

### 覆膜（光膜 / 哑膜）
- **原理一句话**：在印刷品表面热压一层透明薄膜。
- **视觉效果**：光膜=增亮增饱和（颜色更"跳"），哑膜=降反光+细腻触感（更"高级"）。
- **成本档次**：低。是最便宜的表面处理，几乎必做。
- **设计注意**：
  - 户外/人手常摸的（菜单！）必须覆膜，否则一个月就磨花。
  - **雷区**：深色特种纸+亮膜=气泡雪花点全显形；珠光纸+大面积烫金=附着力差会掉。
  - 高级组合：哑膜+局部 UV（整体低反光+局部高亮，反差出层次）。

### 烫金 / 烫银
- **原理一句话**：加热+压力，把电化铝箔转移到承印物上，形成金属光泽。
- **视觉效果**：金/银/镭射金属光泽，贵气、仪式感。辉味李小渔的"鎏金"感就靠它。
- **成本档次**：中。一套版只能烫一种箔，多色=多套版多道工序。
- **设计注意**：
  - 温度 110~150℃，压力/温度/速度不匹配会糊版、飞金、附着不牢。
  - **细线条（<0.2mm）和微文字烫金必须打样**——压力稍大就糊成一团。
  - 烫金面积控制在 40% 以内，满版烫金=土+贵+易脱落。
  - 深色底+烫金是经典，但黑色纸上烫黑金纯属浪费钱（看不见）。

### UV 上光（局部 UV）
- **原理一句话**：在指定区域上一层透明 UV 光油，固化后高亮。
- **视觉效果**："隐约可见"——哑膜底上的高光 logo/纹理，转动角度才显现，含蓄的高级。
- **成本档次**：中。比满版上光贵（要制版套准）。
- **设计注意**：
  - 必须和底色有明度/质感反差——白纸上做透明 UV 等于没做。
  - 套准精度要求高，细小 UV 图案（<3mm）容易套偏。
  - UV 层上再烫金容易掉金，工艺顺序要跟工厂确认。

### 击凸 / 压纹（压凹凸）
- **原理一句话**：阴阳模具压出立体凹凸，无油墨，靠光影呈现。
- **视觉效果**：触感+光影的立体 logo/纹理，低调的贵。
- **成本档次**：中（一套模具费）。
- **设计注意**：
  - 纸张 ≥250g 才压得出效果，薄纸压完背面全鼓包。
  - 击凸深度 0.3~0.5mm 是甜点区，配合预热效果更好。
  - **预算有限时：与其烫金+UV+击凸全上，不如只做击凸但做到极致**——单一工艺的精度比工艺数量更显档次。

### 表面处理雷区速查

| 组合 | 结果 |
|---|---|
| 深色特种纸 + 亮膜 | ❌ 气泡雪花点 |
| 珠光纸 + 大面积烫金 | ❌ 附着力差、运输脱落 |
| 牛皮纸 + 四色印刷 | ❌ 发灰，改专色/黑白 |
| 触感纸 + 烫金/击凸 | ✅ 安全 |
| 哑粉纸 + 局部 UV | ✅ 安全 |
| 深色底 + 烫金 | ✅ 经典 |

## 五、安装方式：三种

### 墙面安装
- **方式**：膨胀螺栓/化学锚栓打墙；轻质牌（KT/薄 PVC）可用结构胶+双面胶。
- **设计影响**：
  - 重型牌（铝塑板/不锈钢）必须在设计稿上**预留安装孔位或背栓位置**，别把重要文字放在打孔区。
  - 混凝土/砖墙最牢；石膏板/空心砖要穿透加固——设计前先问客户墙面材质。
  - 户外墙面牌要考虑**风荷载**：面积越大、越高，固定点越密，龙骨越粗。

### 吊装
- **方式**：吊车整体吊装（大牌）、链条/钢丝绳悬挂（吊牌/灯箱）。
- **设计影响**：
  - 吊牌要做**双面**——背面不是"背面"，是另一面正面。
  - 吊点位置影响平衡：重心偏了牌子会歪，设计重型吊牌时跟结构确认吊点。
  - 大型户外牌吊装要编吊装方案、经纬仪校垂直度（规范 h/2000）——交期里留出报审时间。

### 立地安装
- **方式**：地面预埋螺栓+混凝土基础，立柱撑起牌面（精神堡垒、停车场牌）。
- **设计影响**：
  - **底部 30~50cm 是"脏区"**——泥水飞溅、行人踢碰，重要内容别放太低。
  - 立柱本身也是设计的一部分：颜色跟牌面统一，别让一根镀锌管毁了整个设计。
  - 考虑夜间：要不要预留灯具位置/走线槽。

### 安装通用提醒

- 电气（发光字/灯箱）：电源用**防水型**，进线口密封，整体打胶——返修 90% 是进水。
- 法规：户外大牌可能要报批（城管/市政），设计前先问客户"手续谁办"，别设计完了立不起来。
- 高空作业：2m 以上要脚手架/吊篮，安装费里含不含要提前谈。

## 六、设计—生产对照表

| 设计动作 | 生产视角的提醒 |
|---|---|
| 大面积深色底（黑/深蓝） | 喷绘深色费墨且易偏色；写真黑色用 C70M70Y70K95；UV 打印深色板要先打白底 |
| 很细的线条/小字 | 丝印 <0.3mm 会断线；烫金 <0.2mm 要打样；发光字笔画 <15mm 会断光 |
| 渐变、大面积柔光 | 丝印做不好渐变（断层）；喷绘渐变看距离；UV 打印渐变最稳 |
| 菜单/常触摸的印刷品 | 必须覆膜（哑膜），否则一个月磨花 |
| 户外用的牌子 | KT 板=一次性；写真=见水化；选铝塑板+喷绘/UV，或不锈钢 |
| 发光字标题 | 先定观看距离：<5m 不用冲孔字；深色墙才用背打光字；小字（<10cm）用迷你字 |
| 厦门/漳州户外金属件 | 指定 304 不锈钢，201 一年锈；跟客户说清楚差价买的是"不返工" |
| 超过 1.22×2.44m 的版面 | 铝塑板标准尺寸，拼缝位置设计时藏好 |
| 吊牌/双面牌 | 背面也是正面，两面都要设计 |
| 立地牌 | 底部 30~50cm 别放重要内容；立柱颜色统一 |
| 要烫金的稿子 | 烫金面积 <40%；细线打样；深色底烫金、浅色底别烫同色系 |
| 给工厂的文件 | CMYK 模式；文字转曲；3mm 出血；重要内容离边 ≥5mm；大文件附 JPG 预览图 |

## 七、一句话总结

> **好设计 = 在图纸阶段就替生产排了雷**：材质选对场景、工艺配得上预算、安装有处落脚、文件工厂能直接用。潘熠的模式是"设计包月、生产报价"——设计时多想一层生产，报价时就少一次返工，客户信任就是这么攒出来的。
