## 第三章「商业 LOGO 和 IP 设计」（总第 35–48 节，14 节全部学完）

### 第 35 节：如何设计简约人物卡通 LOGO？（27 分 32 秒）
https://huke88.com/career/video/117-146977.html
- 先定品牌定位与名字，再从名字和品类里提炼元素（如甜品、蛋糕、樱桃），五官与发型用简约线条区分性别年龄，元素与人物结合时修剪重叠线、保持线条干净。
- 可应用：主视觉用简约人物 IP 加品类元素，一眼传达品类与亲和力。

### 第 36 节：如何卡通 IP 插画 LOGO？（23 分 32 秒）
https://huke88.com/career/video/117-146978.html
- 以产品本体（如吐司）直接拟人化，闭眼微笑加腮红传达温暖；手部 3–4 指概括即可，用留白删减次要线条，突出主角、保持简约。
- 可应用：食品广告用产品本体拟人化做主视觉，降低理解成本。

### 第 37 节：AI-新年兔子 IP 形象设计基础篇（13 分 16 秒）
https://huke88.com/career/video/117-147321.html
- 抱柿子取“好事成双”的吉祥寓意；整体偏胖偏 Q、各部位圆润一致，耳朵对称镜像，线条端点圆角，配新年帽、福字菱形与橘红配色。
- 可应用：节日广告用生肖加吉祥谐音做主视觉，快速营造节日氛围。

### 第 38 节：AI-新年兔子 IP 形象设计上装篇（20 分 02 秒）
https://huke88.com/career/video/117-147322.html
- 主角最大最突出，小元素只作衬托；全图描边粗细统一、主体单独编组；服装按身体结构画、配古装腰带与窗花点缀，用橘红、橙红而非大红显年轻，祝福语描边强化后可延展到包装、周边与礼盒。
- 可应用：节日 Campaign 把 IP 加祝福语做成系列 KV 与包装延展。

### 第 39 节：Procreate-国风商业 IP 创造-《吾名虎宝！》（26 分 17 秒）
https://huke88.com/career/video/117-120109.html
- 先定构图与仰视视角、人物占绝对位置；用中线定位五官并微倾表现抬头；先做设定，大脸盘、三角鼻等特征要与设定一致并反复对照；描线干净流畅、闭合便于上色，直接用现成色卡降低试错。
- 可应用：广告 IP 先做设定与色卡，保证多物料形象统一。

### 第 40 节：Procreate-iPad 四格漫画－《虎宝的一天》（35 分 57 秒）
https://huke88.com/career/video/117-121549.html
- 四格按从左到右 1–4 格阅读，先讲清故事再画分镜；做可复用的通用底子（底色、框、文字排版）；形象事先确定、角度可由正面推导，表情靠眉眼嘴角微调，主角最突出、配角不抢戏，颜色要少。
- 可应用：社交广告用四格漫画讲产品痛点与笑点，降低阅读门槛。

### 第 41 节：Procreate-国风商业 IP-招财虎宝（32 分 08 秒）
https://huke88.com/career/video/117-122354.html
- 对称构图只画一半再复制水平翻转，框、灯笼等装饰同理；先用色卡与客户或团队对齐配色，减少主观争议；描线前检查闭合，否则填色会流出、返工成本高；上色用线稿参考图层加剪切蒙版或拖色。
- 可应用：对称式主视觉或海报用半边复制法快速出稿并保证对称。

### 第 42 节：Procreate-iPad 商业 IP 插画-虎宝的诞生（26 分 21 秒）
https://huke88.com/career/video/117-128327.html
- IP 三视图为正面、侧面、背面，用网格与辅助线保证高度与位置对齐；只画一半再复制翻转，侧面注意近大远小，背面可由正面改线得到；线稿单线、实线且必须闭合才能直接拖色；先上底色再用色卡，线稿可变色融入画面。
- 可应用：品牌 IP 手册先定三视图，延展物料不走样。

### 第 43 节：Procreate-商业 IP 插画-如何做出立体感（26 分 02 秒）
https://huke88.com/career/video/117-129507.html
- 二维转三维时在线稿上新建图层并创建剪切蒙版，让线稿融入人物颜色；分亮面与暗面，暗部越往外越轻、过渡自然；加高光与环境光、反光，擦出边缘高光；结构处卡得实、圆润处处理柔和，避免处处生硬。
- 可应用：扁平 IP 在广告中加明暗与环境光，提升立体感与质感而不改造型。

### 第 44 节：Procreate-IP 插画虎宝的表情管理（27 分 27 秒）
https://huke88.com/career/video/117-131434.html
- 在已有基础线稿上扩展表情：关闭颜色图层、复制线稿改眼球位置；奸笑、得意靠眉眼压低与嘴角变化，拉眼皮、眯眼等小动作强化情绪，注意前后遮挡；线条流畅闭合，才能快速吸色上色；同一方法可批量衍生表情与动作，不必每张重画。
- 可应用：广告社交物料用同一 IP 做多表情，保持统一又增加互动感。

### 第 45 节：Procreate-IP 趣味插画虎课牌（27 分 58 秒）
https://huke88.com/career/video/117-132333.html
- 把虎宝形象加进扑克牌，4 个 K 对应“课”；有固定 IP 设定，画什么姿势都有依据；只画半边再复制水平翻转，保证对称、注意牌面方向；线稿流畅闭合，用参考图层吸已有 IP 色，颜色少而固定。
- 可应用：把品牌字母或符号与 IP 结合做周边，既是产品又是品牌传播。

### 第 46 节：Procreate-iPad 画 IP 门神虎宝降妖镇邪（29 分 43 秒）
https://huke88.com/career/video/117-132416.html
- IP 不是一下画成的，借鉴已有造型、一步步加服饰与姿势推进；把原 IP 放一边做参考，颜色与形状保持一致；草图先定比例与透视，再加武器、帽子、铠甲等门神元素；线稿干净闭合、内外线粗细有区分；配色找传统年画、门神色卡，不凭感觉配。
- 可应用：节日或国风广告用传统元素加 IP 重组，既有文化感又不丢品牌识别。

### 第 47 节：Procreate-IP 插画虎宝的丝绸之路（29 分 01 秒）
https://huke88.com/career/video/117-132674.html
- 竖构图、虎宝占画面主要位置，先定位置再加元素；用骆驼局部暗示丝绸之路，不必画全，再加丝路植物与服饰；画面节奏上疏下密有度，不能处处塞满，留太阳、云等呼吸感；中线定仰头角度与五官，遵循近大远小；色卡先定国风感觉与明度对比。
- 可应用：文旅或国风广告用“主角加地域符号加竖构图”做海报，主次清晰。

### 第 48 节：Procreate-IP 趣故事插画-虎宝的一天（31 分 42 秒）
https://huke88.com/career/video/117-135055.html
- 四格趣故事用黄色底加四个白色矩形框、再加标题文字；先定故事与每格交代，再画草图，主角 IP 做参考；草图阶段只抓大关系、不抠细节；线稿单线、流畅干净、闭合是上色前提；颜色要少、用 IP 已有颜色；总结为空间透视、颜色与线条三点。
- 可应用：用四格故事做品牌日常或节日系列帖，讲清场景又易传播。

## 今日干货总汇
- IP 先定设定再延展：定位与名字定元素、三视图定角度、色卡定配色，设定齐了多物料才不走样。
- 简约与主次是两条主线：五官、颜色、线条都要少而干净；主角最大最突出，小元素只衬托。
- 可复用的提效手法：半边复制翻转做对称、通用底子做四格、同一线稿批量衍生表情、线稿闭合与参考图层上色。
- 节日与国风打法：生肖加吉祥谐音、传统色卡与门神元素、地域符号加竖构图，都是现成的广告主视觉套路。
